# 记忆索引

[English](README.md) | [简体中文](README_CN.md)

> `README.md` 是记忆系统规则的唯一规范来源。本文仅作为翻译参考；如有任何内容与英文版不一致，以英文版为准。

> 此目录是系统的持久记忆。通过本索引定位相关记忆，无需默认加载所有文件。

## 记忆区域

| 文件 | 用途 | 读取时机 |
| --- | --- | --- |
| [profile.md](profile.md) | 身份、职责、背景和沟通特征。 | 需要身份上下文或个性化信息时。 |
| [relationships.md](relationships.md) | 重要人物、团队、组织及其关系。 | 任务涉及已知人物、角色或协作时。 |
| [knowledge.md](knowledge.md) | 已验证的事实、概念和可复用的项目知识。 | 需要事实或项目上下文时。 |
| [goals.md](goals.md) | 长期和当前目标、优先级、状态及完成条件。 | 规划工作或选择下一步行动时。 |
| [focus.md](focus.md) | 当前任务上下文、关注点、进度、下一步和阻塞项。 | 继续或恢复当前工作时。 |
| [experiences.md](experiences.md) | 重要事件、结果、决策和经验教训。 | 遇到相似情况或需要回顾历史时。 |
| [principles.md](principles.md) | 价值观、工作偏好、行为原则和安全边界。 | 作出判断、选择方案或检查边界时。 |
| [reminders.md](reminders.md) | 指定日期、时间和周期性提醒。 | 检查日程或扫描到期事项时。 |

## 运行规则

1. 只读取与当前任务相关的记忆文件。
2. 将记忆视为上下文，而不是绝对正确的事实；准确性重要时应进行验证。
3. 保存持久且可复用的信息，不保存完整的对话记录。
4. 优先更新已有条目，避免创建重复内容。
5. 区分已确认的事实、推断和仍需验证的事项。
6. 保持 `focus.md` 简短，并随着当前任务的变化进行重写。
7. 不得保存密码、访问令牌、私钥或其他秘密信息。
8. 事实发生变化时保留有价值的历史；适当时在 `experiences.md` 中记录变化。

## 记忆元数据

持久记忆条目应包含：

- `Updated`：条目最近一次确认或修改的日期，格式为 `YYYY-MM-DD`。
- `Source`：信息来源，例如 `User`、文件路径或 URL。
- `Confidence`：仅使用 `Confirmed`、`Inferred` 或 `Unverified`。

明确陈述或经过独立验证的信息使用 `Confirmed`，合理推断使用 `Inferred`，仍需核实的信息使用 `Unverified`。

## 推荐读取顺序

1. 当任务涉及判断、偏好或安全时，读取 `principles.md`。
2. 读取 `focus.md`，恢复当前任务上下文。
3. 根据需要读取上表中的一个或多个领域文件。
4. 只有在处理日程或到期事项时才检查 `reminders.md`。
