# Green Phosphor Command Story

## Overview

An old CRT terminal tells a procedural story through typed commands, scrolling logs, ASCII diagrams, progress states, and glowing block banners. Choose this for a procedural terminal narrative driven by prompts, commands, diagrams, and system responses.

## Signature Features

- Curved dark screen with green phosphor
- Monospaced commands typed at credible speed
- Scrolling logs and determinate progress bars
- ASCII or block-letter banners for key names and figures
- Bloom, scan lines, persistence, cursor blink, and restrained screen noise

## Style Prompt

Frame the experience as one coherent terminal session. Begin at a prompt, type a meaningful command character by character, echo it, and return structured logs whose timestamps, paths, statuses, and values relate to the user's subject. Use determinate progress bars for actual stages and pause or retry when the story includes failure. Render diagrams, tables, small charts, and large block-letter banners from monospaced characters, keeping columns aligned. Simulate a curved CRT with tight green phosphor bloom, faint scan lines, modest persistence trails on scrolling text, a blinking cursor, subtle brightness fluctuation, and sparse noise. Let lines scroll naturally when the viewport fills and preserve earlier context where useful. Use one bright result banner for the climax and return to a prompt or shutdown state.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.
