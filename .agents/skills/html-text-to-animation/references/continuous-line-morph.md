# Continuous-Line Morph

## Overview

One unbroken ink line draws every subject and transforms scenes without ever leaving the page. Choose this when the unbroken line repeatedly becomes different objects and the transformation itself is the main event.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: journeys, causal explanations, identity shifts, and elegant visual metaphors
- Complexity: Advanced

## Signature Features

- One continuous visible stroke.
- Scenes transform through redrawing rather than cuts.
- Line tension and speed carry emotion.
- Negative space remains dominant.

## Style Prompt

Create a polished visual narrative in the **Continuous-Line Morph** style. Plan one traceable path through the entire narrative. Let the line pause, reverse, knot, open, and reshape into each new subject while preserving continuity.

Translate the user's material into this visual grammar rather than copying source examples. Preserve supplied wording, evidence, and attribution; select an implementation appropriate to the material.

## Customizable Elements

- Subject, copy, duration, aspect ratio, pacing, palette emphasis, and implementation method.

## Avoid

- Choose **Single-Line Narrative** when chronology matters more than metamorphosis.
- Hidden cuts, multiple independent lines, dense hatching, arbitrary scribble, or transformations that break the path.
- Never invent documents, measurements, quotations, sources, or factual evidence.
- Do not use surface effects as a substitute for narrative structure.
