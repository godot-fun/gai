# Protein-Folding Ribbon Model

## Overview

Amino-acid chains fold into helices, sheets, loops, and binding pockets without losing sequence continuity.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: biology, medicine, structure, and functional transformation

## Signature Features

- Keep one continuous chain visible as it transitions from sequence to helices, sheets, loops, and a compact tertiary form; use a limited structural color code.
- Fold in staged constraints—local secondary structure before long-range contacts—then orbit gently to reveal a binding pocket without tangling orientation.
- Use clean scientific labels outside the molecule and a small sequence strip or legend when helpful.
