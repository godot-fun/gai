# Exploded Teardown

## Overview

A real product separates along a controlled axis so engineering layers, parts, and file-derived specifications become visible.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: product anatomy, repair, manufacturing, and hardware explanation

## Signature Features

- Studio packshot baseline.
- Parts derived from real CAD or documentation.
- Ordered axial separation.
- Labels use authentic part and material data.

## Style Prompt

Create a polished visual narrative in the **Exploded Teardown** style. Begin with the assembled product, lift layers in engineering order, move the camera between them, and annotate only the part currently being explained. Close by reassembling into the original object.

## Avoid

- Arbitrary floating parts, fake specifications, explosive motion, labels on every component at once, or a final object that does not align.
