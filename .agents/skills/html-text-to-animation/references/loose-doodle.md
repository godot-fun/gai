# Loose Doodle

## Overview

Crooked energetic lines and visible construction marks turn imperfection into personality.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: self-deprecation, rough ideas, youth, and informal explanation

## Signature Features

- Loose uneven line work.
- Visible sketch corrections.
- Sparse spot color.
- Spontaneous handwritten energy.

## Style Prompt

Create a polished HTML animation in the **Loose Doodle** style. Animate lines as if thinking aloud: draw, reconsider, cross out, circle, and annotate. Keep the mess intentionally composed.

## Avoid

- Polished vector symmetry, dense illegible scribble, full-color rendering, or fake randomness on every frame.
