# Loose Doodle

## Overview

Crooked energetic lines and visible construction marks turn imperfection into personality.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: self-deprecation, rough ideas, youth, and informal explanation
- Complexity: Moderate

## Signature Features

- Loose uneven line work.
- Visible sketch corrections.
- Sparse spot color.
- Spontaneous handwritten energy.

## Style Prompt

Create a polished HTML animation in the **Loose Doodle** style. Animate lines as if thinking aloud: draw, reconsider, cross out, circle, and annotate. Keep the mess intentionally composed.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Polished vector symmetry, dense illegible scribble, full-color rendering, or fake randomness on every frame.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
