# Live-Drawn Whiteboard

## Overview

A concept is explained as a marker draws diagrams and labels in true stroke order on a warm white board. Choose this for a single fixed board where a hand visibly constructs one explanation in real time.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: concepts, principles, and causal explanation

## Signature Features

- One drawing action at a time.
- Dark hand-drawn line plus one accent.
- Diagram order follows narration.

## Style Prompt

Create a polished visual narrative in the **Live-Drawn Whiteboard** style. Begin from an almost empty board, draw outlines before color, keep the active marker near the current stroke, and leave completed ideas spatially organized.

## Avoid

- Choose **Traveling Whiteboard Explainer** for a long connected journey, **Engineering Briefing Board** for evidence and measurements, or **Used Whiteboard Lecture** for accumulated classroom residue.
