# L-System Botanical Growth

## Overview

A recursive grammar unfolds stems, branches, leaves, and flowers from a compact generative rule.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: growth, ancestry, procedural nature, branching knowledge, and long-term development

## Signature Features

- Repeated symbols become nested branching structures with consistent angles, scale ratios, and botanical hierarchy.
- Draw growth from trunk to twig in generational passes, with small secondary sway only after construction.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.
