# Kawaii Mascot

## Overview

Bean-like forms, dot eyes, tiny mouths, and soft color create maximum warmth with minimal detail.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: stickers, onboarding, light humor, and comforting moments
- Complexity: Moderate

## Signature Features

- Rounded compact body shapes.
- Dot eyes and tiny mouth.
- Pastel palette with one stronger accent.
- Small symbolic reaction marks.

## Style Prompt

Create a polished HTML animation in the **Kawaii Mascot** style. Use minimal poses and let small tilts, blinks, and reaction symbols carry emotion. Protect generous space around the mascot.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.

## Avoid

- Do not copy example brands, characters, or sample copy from the source material.
