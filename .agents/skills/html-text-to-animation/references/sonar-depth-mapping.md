# Sonar Depth Mapping

## Overview

Acoustic pings sweep underwater terrain and convert return time into bands, points, and relief.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: oceans, navigation, archaeology, and hidden landscapes

## Signature Features

- Build a dark-water section or plan view with a transducer, measured beam cone, return points, and a progressively resolved seabed.
- Emit paced pings, show time-of-flight returns, and accumulate them into bathymetric relief as the platform moves; track alongside the survey path.
- Use naval-style monospaced data, depth ticks, and cyan or amber returns against navy.

## Style Prompt

Create a polished HTML animation in the **Sonar Depth Mapping** style. Build a dark-water section or plan view with a transducer, measured beam cone, return points, and a progressively resolved seabed. Emit paced pings, show time-of-flight returns, and accumulate them into bathymetric relief as the platform moves; track alongside the survey path. Use naval-style monospaced data, depth ticks, and cyan or amber returns against navy. Make every transition arise from the optical or scientific process itself, and preserve enough negative space for the supplied message to remain primary.

## Avoid

- Avoid radar sweeps in air, continuous laser beams, instant complete terrain, random fish icons, or depths unconnected to return time.
