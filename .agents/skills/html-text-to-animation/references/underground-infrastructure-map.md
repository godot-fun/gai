# Underground Infrastructure Map

## Overview

Street level lifts to reveal tunnels, pipes, cables, foundations, and hidden service networks beneath a city.

## Metadata

- Collection: Architecture and Spatial Installation
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: infrastructure, cities, systems, and unseen dependencies

## Signature Features

- Layer street, foundations, rail, water, sewer, power, and data at distinct depths with section cuts and access points.
- Lift the surface, trace one network at a time, show crossings and maintenance routes, then reconnect each system to above-ground users.
- For **Underground Infrastructure Map**, choose a restrained architectural palette led by material color and one light or wayfinding accent; preserve human scale and believable structure.

## Style Prompt

Create a polished HTML animation in the **Underground Infrastructure Map** style. Layer street, foundations, rail, water, sewer, power, and data at distinct depths with section cuts and access points. Lift the surface, trace one network at a time, show crossings and maintenance routes, then reconnect each system to above-ground users. Choose a restrained palette led by structural material, environmental light, and one wayfinding or performance accent; preserve human scale. Use quiet modernist typography on plans, plaques, or negative space, never as weightless decoration inside the built volume. Organize the message around spatial sequence, structural behavior, or installation mechanics so every transformation remains inhabitable and legible.

## Avoid

- Avoid spaghetti pipes, networks crossing without clearance, neon cyber tunnels, unlabeled depths, or implying exact geography without data.
- Do not add architectural detail that ignores structure, circulation, material span, installation mechanics, or human scale.
