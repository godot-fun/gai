# Cosmic Scale Pullback

## Overview

A point unfolds into a scene, recedes until the scene becomes a point in space, then leads into another world.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: scale, nested systems, perspective shifts, and connected ideas

## Signature Features

- Continuous scale transformation.
- Each level preserves a visual anchor.
- Pullback and push-in form one path.

## Style Prompt

Create a polished visual narrative in the **Cosmic Scale Pullback** style. Choose nested scales with credible spatial relationships, maintain the anchor through every transition, and pause briefly when the viewer recognizes each new level.

## Avoid

- Avoid arbitrary zooms, losing the visual anchor between scales, or presenting nested worlds without credible spatial relationships.
