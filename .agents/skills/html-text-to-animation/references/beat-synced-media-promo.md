# Beat-Synced Media Promo

## Overview

A polished product-and-footage montage in which typographic hook, interface, scanned media wall, 3D carousel, campaign panel, and statistics all land exactly on musical structure.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Best for: A polished product-and-footage montage in which typographic hook, interface, scanned media wall, 3D carousel, campaign panel, and statistics all land exactly on musical structure.

## Signature Features

- Word-by-word opening hook on a bright stage
- Product interface shown at usable scale
- Real media organized as scan wall and spatial carousel
- Phone or product beside a campaign panel
- Push-cut statistics and every edit tied to a beat

## Style Prompt

Map the entire track before editing and designate downbeats, fills, drops, and breath points. Open with a short hook that arrives word by word on a clean light stage, using each beat to change scale, crop, or emphasis without sacrificing readability. Show the actual interface next at a size where its key interaction can be understood. Move into a dark media stage where real clips form a scanned wall, then reorganize them into a spatial carousel with one chosen clip facing front. Pair the product or phone with a campaign panel that explains the relationship between content and result. Reveal only the strongest metrics through axial push cuts timed to accented hits. Keep footage color coherent, motion direction continuous, and transitions motivated by a screen, tile, or product edge.

## Avoid

random speed ramps, cuts on every subdivision, illegible UI, fake footage placeholders, too many stats, music-independent animation, and a montage that never establishes what is being promoted.
