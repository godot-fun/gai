# Constructivist Montage

## Overview

Archive footage, photographs, documents, and type become one red-black ink-and-paper machine.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: political history, labor, conflict, and forceful argument

## Signature Features

- Diagonal structural axes.
- One red accent over black and paper.
- Cut-out figures stacked into graphic masses.
- Two images collide to create a third idea.

## Style Prompt

Create a polished visual narrative in the **Constructivist Montage** style. Treat every element as printed material: crop hard, rotate on diagonals, drive type through bands, and cut on an industrial beat. Use red to mark facts, thresholds, and ideological pressure.

## Avoid

- Soft collage, many colors, ornamental distress, smooth corporate motion, or symbolic juxtapositions with no argumentative meaning.
