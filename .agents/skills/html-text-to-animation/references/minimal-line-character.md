# Minimal Line Character

## Overview

A person is reduced to a few confident strokes against an almost empty field.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: universal human situations, self-reflection, and simple conceptual humor

## Signature Features

- Very few continuous strokes.
- Neutral open background.
- Pose and timing carry all expression.
- No unnecessary facial detail.

## Style Prompt

Create a polished HTML animation in the **Minimal Line Character** style. Design each pose as a clear silhouette and animate through economical gesture changes. Use one accent only when an object or emotion needs emphasis.

## Avoid

- Sketch clutter, realistic anatomy, many props, textured backgrounds, or decorative motion.
