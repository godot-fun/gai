# Mathematical Visual Proof

## Overview

Equations and geometric objects transform on a dark field so each symbolic step becomes spatially intuitive.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: mathematics, physics, algorithms, and quantitative reasoning

## Signature Features

- Every transformation preserves mathematical meaning.
- Color identifies stable concepts.
- Camera follows the proof structure.

## Style Prompt

Create a polished visual narrative in the **Mathematical Visual Proof** style. Begin from a concrete question, introduce notation only when needed, animate equivalence step by step, and keep previous relationships visible long enough to compare.

## Avoid

- Avoid mathematically invalid transformations, decorative equations, unexplained notation, or camera movement that hides equivalence steps.
