# Embroidered Thread Drawing

## Overview

Colored thread travels through fabric, leaving stitches, knots, and layered directionality as visible linework.

## Metadata

- Collection: Print, Textile and Physical Craft
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: care, memory, handmade diagrams, and decorative narrative

## Signature Features

- Use close fabric grain, a visible needle, thread tension, stitch direction, knots, and occasional layered colors.
- Pierce front and back correctly, pull each stitch taut, vary stitch family by form, and let the camera follow the working point.
- For **Embroidered Thread Drawing**, let tool marks, joins, surface response, and small process variation provide material truth; choose colors plausible for the named craft.
