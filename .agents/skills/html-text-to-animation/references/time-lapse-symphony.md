# Time-Lapse Symphony

## Overview

A city is edited as minimalist music, turning traffic, crowds, weather, and light into recurring visual phrases.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: cities, infrastructure, collective rhythm, and wordless transitions
- Complexity: Advanced

## Signature Features

- Time-lapse movement behaves like musical texture.
- Cut density follows subdivisions of the score.
- One near-still counterpoint interrupts the flow.
- A downbeat hard-cut provides closure.

## Style Prompt

Create a polished visual narrative in the **Time-Lapse Symphony** style. Build recurring motifs across locations, increase cut frequency with the score, and contrast accelerated systems with one held human-scale image. Let music carry structure without narration.

Translate the user's material into this grammar rather than copying the source examples. Preserve supplied wording and factual attribution, and choose an HTML-native or composited implementation appropriate to the evidence and visual material.

## Customizable Elements

- Subject, evidence, copy, duration, aspect ratio, pacing, and implementation method.
- Adapt palette details only when the defining visual hierarchy remains intact.

## Avoid

- Random pretty time-lapse, constant speed, generic inspirational pacing, or an ending that fades without rhythmic resolution.
- Never invent documents, measurements, quotations, sources, or factual evidence.
- Do not use surface effects as a substitute for the style's narrative structure.
