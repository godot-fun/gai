# Holographic Foil Embossing

## Overview

Embossed foil flashes spectral highlights only where grazing light crosses its raised microtexture.

## Metadata

- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: certificates, luxury identity, collectible graphics, and celebratory reveals
- Complexity: Moderate to advanced

## Signature Features

- Treat the frame as dark paper with one embossed foil emblem; combine shallow relief, micro-groove diffraction, silver base metal, and narrow spectral flashes.
- Move a long strip light across the relief so only grazing facets ignite; use a slow product-camera tilt and settle on the tactile stamped edge.
- Use restrained high-contrast serif or engraved capitals, preferably blind-embossed before the foil catches light.
