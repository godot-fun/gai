# Transit Map Process

## Overview

A transit-diagram grammar turns a process into routes, stations, transfers, and destinations. Choose this for a general workflow or learning path encoded as routes, stations, transfers, and destinations.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: workflows, learning paths, decisions, and multi-stage systems
- Complexity: Moderate

## Signature Features

- Clean colored routes.
- Consistent station symbols.
- Clear transfer hierarchy.
- Destination-oriented reading.

## Style Prompt

Create a polished HTML animation in the **Transit Map Process** style. Trace the active route as the story progresses, dim inactive branches, and reveal transfers only when they matter.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Choose **Narrative Transit Map** when characters or story events travel through the network.
- Geographic realism, crossing-line clutter, too many route colors, unlabeled stops, or animated trains distracting from the process.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
