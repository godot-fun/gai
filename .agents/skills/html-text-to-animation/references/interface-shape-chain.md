# Interface Shape Chain

## Overview

One continuous shape transforms through button, spinner, player, slider, toggle, and other interface roles after real pointer actions.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: feature lists, automation examples, and connected UI concepts

## Signature Features

- One persistent geometric identity.
- Every state change follows an input.
- Morphs preserve area or anchor where possible.

## Style Prompt

Create a polished visual narrative in the **Interface Shape Chain** style. Let a pointer trigger each transformation, demonstrate the new function briefly, and carry one edge, color, or center point continuously through the chain.

## Avoid

- Avoid unrelated UI components, transformations without user input, or morphs that lose every persistent geometric anchor.
