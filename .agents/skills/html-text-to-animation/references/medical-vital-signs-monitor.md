# Medical Vital-Signs Monitor

## Overview

Waveforms, numeric vitals, alarms, and interventions evolve together on a disciplined clinical timeline.

## Signature Features

- Use a clinical dark display with synchronized ECG, oxygen, respiration, pressure, numeric values, and alarm limits.
