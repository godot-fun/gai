# Financial Order-Book Pulse

## Overview

Bid and ask depth shifts around a central price while trades consume liquidity in discrete bursts.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: markets, supply and demand, volatility, and transactional systems

## Signature Features

- Center the current price between stacked bid and ask depth, recent trades, spread, and cumulative liquidity.
- Let limit orders enter, cancel, and be consumed at discrete price levels; move the midpoint only when available depth changes.
- For **Financial Order-Book Pulse**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Financial Order-Book Pulse** style. Center the current price between stacked bid and ask depth, recent trades, spread, and cumulative liquidity. Let limit orders enter, cancel, and be consumed at discrete price levels; move the midpoint only when available depth changes. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

## Avoid

- Avoid casino styling, random bar pulsing, guaranteed-profit implications, or price motion unrelated to executed orders.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
