# Living Blueprint

## Overview

White technical line work is drawn in drafting order on Prussian-blue cyanotype paper while annotations respond to the construction. Choose this when the blueprint must draw itself in authentic drafting order and annotations react to construction.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: mechanisms, architecture, engineering, and procedural explanation

## Signature Features

- Prussian-blue paper field.
- White lines follow drafting hierarchy.
- Construction precedes finished outline.
- Dimensions and notes attach to real geometry.

## Style Prompt

Create a polished visual narrative in the **Living Blueprint** style. Draw axes and reference geometry first, add object outlines and sections, then introduce dimensions and animated callouts. Keep line weights semantically distinct.

## Avoid

- Choose **Isometric Blueprint** for a finished technical illustration without a construction performance.
- Sci-fi HUD styling, fake equations, decorative measurements, inconsistent projection, or glowing neon lines.
