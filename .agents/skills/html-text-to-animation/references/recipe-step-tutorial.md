# Recipe-Step Tutorial

## Overview

A process is taught like a cocktail recipe: begin empty, add one named quantity at a time, and reveal the finished result.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: simple builds, repeatable methods, and ingredient-based instruction

## Signature Features

- Empty starting vessel.
- Each addition named and quantified.
- Final result proves the sequence.

## Style Prompt

Create a polished visual narrative in the **Recipe-Step Tutorial** style. Keep camera and container stable, introduce one component per beat, and distinguish required ingredients from optional variations.

## Avoid

- Avoid adding several components at once, omitting quantities when they matter, changing the container viewpoint, or revealing a result unrelated to the steps.
