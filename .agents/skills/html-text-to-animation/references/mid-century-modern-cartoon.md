# Mid-Century Modern Cartoon

## Overview

Geometric characters, sparse backgrounds, and bold limited color recall optimistic 1950s commercial animation.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: designed explainers, retro advertising, and witty character scenes
- Complexity: Moderate

## Signature Features

- Geometric simplified anatomy.
- Flat limited palette.
- Asymmetric layouts.
- Selective angular motion.

## Style Prompt

Create a polished HTML animation in the **Mid-Century Modern Cartoon** style. Use strong silhouettes, held poses, and economical transitions. Let background shapes support composition rather than simulate a real environment.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Rubber-hose curves, modern corporate gradients, dense scenery, realistic perspective, or soft 3D rendering.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
