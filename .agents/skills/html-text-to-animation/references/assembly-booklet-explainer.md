# Assembly Booklet Explainer

## Overview

An aged-cream instruction booklet turns abstract information into numbered line-art assembly steps, physical metaphors, page slides, and a final verification stamp.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Large chapter numeral and cream manual page
- Flat isometric line art with a small scale figure
- Shipping box, hardware, tags, coins, belts, or outlets as concrete metaphors
- Pages slide over one another
- Components build in sequence before their step number locks

## Style Prompt

Translate the subject into a sequence of assembly operations. Open each manual page with a large step numeral, then draw an isometric hero object or system in restrained dark line on aged cream paper. Include a small neutral figure for scale and replace abstract charts with understandable hardware metaphors—boxes, tags, coin stacks, conveyor sections, plugs, fasteners, shelves, or modules. Animate every diagram in construction order: parts enter, align, connect, rotate, tighten, and settle; only then should arrows, labels, and the step number snap into final state. Turn or slide pages physically over one another instead of cutting. Use warning crosses for wrong assemblies, checkmarks for verified states, and consistent part IDs across pages. End on a completed object and stamped approval held still.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

copying a furniture brand, impossible perspective, ornamental arrows, parts appearing already assembled, unreadable tiny notes, too many colors, page transitions unrelated to paper, and metaphors that obscure rather than explain the data.
