# Zoetrope Slit Drum

## Overview

A rotating slotted drum turns a ring of sequential drawings into a brief, mechanically gated motion cycle.

## Metadata

- Collection: Motion Styles
- Medium: HTML, CSS, SVG, Canvas, or WebGL
- Best for: short cyclic actions, motion history, and tactile optical-toy demonstrations

## Signature Features

- Sequential images line the inside of a physical drum.
- Narrow viewing slits interrupt the image stream at regular intervals.
- Rotation speed visibly controls when separate drawings become continuous motion.

## Style Prompt

Create a polished HTML animation in the **Zoetrope Slit Drum** style. Establish the stationary drum and individual frames before accelerating it. Let the viewer alternate between an exterior view of the slits and a slit-gated view of one clean repeating action. Preserve stepped mechanical timing, paper texture, and a readable relationship between frame count and rotation speed.

## Avoid

- Avoid crossfading frames, hiding the drum mechanism, using a non-looping action, or making the image animate before the viewing slits align.
