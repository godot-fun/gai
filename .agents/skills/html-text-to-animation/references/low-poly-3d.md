# Low-Poly 3D

## Overview

A small number of visible facets describe objects with crisp economical form. Choose this when visible economical facets and deliberately low polygon count define every object.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: technology, maps, abstract worlds, and structural visualization

## Signature Features

- Deliberately limited polygon count.
- Faceted light changes.
- Simple silhouettes.
- Restrained material palette.

## Style Prompt

Create a polished HTML animation in the **Low-Poly 3D** style. Let facets catch broad light shifts and use slow camera movement to clarify form. Keep geometry intentional rather than merely low resolution.

## Avoid

- Choose **Toon-Shaded 3D** for smooth models with cel bands, or **Cinematic Rounded 3D** for soft sculpted character appeal.
- Smooth subdivision, detailed textures, noisy triangulation, glossy realism, or too many tiny facets.
