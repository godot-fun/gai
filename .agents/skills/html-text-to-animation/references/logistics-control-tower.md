# Logistics Control Tower

## Overview

Shipments move across a network while delays, capacity, inventory, and rerouting propagate through the plan.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: supply chains, operations, dependencies, and recovery
- Complexity: Moderate to advanced

## Signature Features

- Use a geographic network beside shipment lanes, inventory nodes, capacity bars, and an exception queue.
- Propagate delay from one leg into downstream arrivals, then animate rerouting and recovery with explicit before-and-after timing.
- For **Logistics Control Tower**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Logistics Control Tower** style. Use a geographic network beside shipment lanes, inventory nodes, capacity bars, and an exception queue. Propagate delay from one leg into downstream arrivals, then animate rerouting and recovery with explicit before-and-after timing. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

Adapt subject matter, wording, duration, and aspect ratio to the user's material. Preserve supplied text unless rewriting is requested, and simplify secondary detail before compromising the defining construction logic.

## Customizable Elements

- Adjust scenario, data density, update cadence, annotation depth, alert severity, and the balance between overview and inspection.
- Change layout, status palette, map or graph scale, and viewpoint without breaking units, chronology, topology, or state semantics.

## Avoid

- Avoid decorative moving trucks, impossible travel times, hidden bottlenecks, or green status everywhere despite unresolved delays.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
- Keep essential text outside dense movement and preserve a clear reduced-motion end state.
