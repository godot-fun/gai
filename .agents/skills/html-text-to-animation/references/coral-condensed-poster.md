# Coral Condensed Poster

## Overview

Tall uppercase typography and a coral accent create a direct, sunlit poster system. Choose this for sunlit directness built from tall condensed uppercase type and a flat coral accent.

## Metadata

- Collection: Ready-Made Layouts
- Medium: HTML, CSS, SVG, or Canvas
- Best for: short announcements, event cards, social headlines, and upbeat chapter breaks
- Complexity: Moderate

## Signature Features

- Condensed uppercase hero type.
- Cream and coral high-contrast palette.
- Simple rectangular crops and rules.
- Fast poster-like hierarchy.

## Style Prompt

Create a polished HTML animation in the **Coral Condensed Poster** style. Use a few enormous words, crop them confidently, and introduce coral as a solid field or underline. Animate with vertical wipes and tight staggered tracking, then hold on a clean poster frame.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Choose **Bold Editorial Poster** for italic magazine drama, or **Screen-Print Poster** for tactile spot-color production.
- Long prose, delicate serif headlines, multiple warm accents, soft gradients, or bouncing letters.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
