# Beat-Locked Pictograms

## Overview

A square-grid core graphic, geometric pictograms, and masked bilingual type form a drum-synchronized flash-card film.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: fast explainers, campaigns, music-led facts, and bilingual messaging
- Complexity: Advanced

## Signature Features

- Circle and half-disc grid cells.
- Round-capped bar pictograms.
- Bold type rises from masks.
- Every major change lands on a beat.

## Style Prompt

Create a polished visual narrative in the **Beat-Locked Pictograms** style. Limit the vocabulary to grid cells, pictograms, and type. Slide rows independently, transform symbols by component reuse, and reserve hard cuts for strong drum hits.

Translate the user's material into this visual grammar rather than copying source examples. Preserve supplied wording, evidence, and attribution; select an implementation appropriate to the material.

## Customizable Elements

- Subject, copy, duration, aspect ratio, pacing, palette emphasis, and implementation method.

## Avoid

- Illustrative characters, off-beat easing, many shape families, ornamental backgrounds, or bilingual text with unequal hierarchy.
- Never invent documents, measurements, quotations, sources, or factual evidence.
- Do not use surface effects as a substitute for narrative structure.
