# First-Person Drawn Stop Motion

## Overview

A hand-drawn object speaks for itself through frame-by-frame wobble and direct first-person narration.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: tool mascots, object stories, self-aware humor, and introductions

## Signature Features

- Visible redraw variation.
- Object is the narrator.
- Pose-to-pose handmade timing.

## Style Prompt

Create a polished visual narrative in the **First-Person Drawn Stop Motion** style. Give the object a simple expressive silhouette, use limited mouth and body poses, and synchronize imperfections consistently rather than randomizing every frame.

## Avoid

- Avoid smooth vector tweening, random line jitter, third-person narration, or redraw variation that obscures the object silhouette.
