# Emotional Contour Map

## Overview

Animated contour lines turn an inner emotional state into a shifting topography.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: anxiety, layered feelings, intensity, and the terrain of memory

## Signature Features

- Nested contours encode changing intensity.
- Spacing tightens around emotional pressure points.
- The field moves organically while retaining map-like precision.

## Style Prompt

Create a polished HTML animation in the **Emotional Contour Map** style. Build one dominant contour mass with quieter echoes, grow the lines outward in sequence, and let them breathe after formation. Use fine monochrome strokes and reserve one accent contour for the central tension.

## Avoid

- Random topographic wallpaper, noisy warping, thick multicolor bands, literal geographic labels, or text over dense lines.
