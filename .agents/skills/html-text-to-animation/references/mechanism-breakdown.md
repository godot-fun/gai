# Mechanism Breakdown

## Overview

A tool is opened into stages so inputs, transformations, decisions, and outputs can be followed in operating order.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: workflows, automation, devices, and how-it-works explanation
- Complexity: Moderate to advanced

## Signature Features

- Visible input-to-output path.
- Components activate in causal order.
- State changes remain traceable.

## Style Prompt

Create a polished visual narrative in the **Mechanism Breakdown** style. Show the intact system first, separate functional modules, run one example through them, and reassemble the whole with the causal path still apparent.

Adapt the subject, copy, duration, aspect ratio, and implementation method while preserving the defining narrative and motion logic. Keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, copy, duration, aspect ratio, palette, pacing, and implementation method.

## Avoid

- Do not copy sample brands, characters, or wording from the source material.
- Do not add motion that has no explanatory, rhythmic, or emotional purpose.
- Preserve readability and one dominant idea per beat.
