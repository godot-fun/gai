# Mechanism Breakdown

## Overview

A tool is opened into stages so inputs, transformations, decisions, and outputs can be followed in operating order.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: workflows, automation, devices, and how-it-works explanation

## Signature Features

- Visible input-to-output path.
- Components activate in causal order.
- State changes remain traceable.

## Style Prompt

Create a polished visual narrative in the **Mechanism Breakdown** style. Show the intact system first, separate functional modules, run one example through them, and reassemble the whole with the causal path still apparent.

## Avoid

- Avoid exploded parts with no operating order, skipped state changes, or an output whose causal path cannot be traced back to the input.
