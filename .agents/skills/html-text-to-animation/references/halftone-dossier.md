# Halftone Dossier

## Overview

A retro printed case file reveals evidence through cream paper, flat inks, halftone exhibits, stamps, and heavy headlines.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: investigations, profiles, satirical files, and evidence-led character stories
- Complexity: Advanced

## Signature Features

- One exhibit introduced at a time.
- Heavy headline with misregistered shadow.
- Rubber stamps provide status and judgment.
- Thick-outlined figures share the print language.

## Style Prompt

Create a polished visual narrative in the **Halftone Dossier** style. Structure the sequence as a file being opened and read: cover, exhibit, annotation, stamp, and conclusion. Use a limited spot palette and clear evidence numbering.

Translate the user's material into this visual grammar rather than copying source examples. Preserve supplied wording, evidence, and attribution; select an implementation appropriate to the material.

## Customizable Elements

- Subject, copy, duration, aspect ratio, pacing, palette emphasis, and implementation method.

## Avoid

- Conspiracy-board strings, modern glass UI, meaningless stamps, excessive distress, or evidence shown without reading order.
- Never invent documents, measurements, quotations, sources, or factual evidence.
- Do not use surface effects as a substitute for narrative structure.
