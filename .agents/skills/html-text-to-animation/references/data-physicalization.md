# Data Physicalization

## Overview

Statistics become countable physical objects arranged to exact scale and photographed as a crafted installation. Choose this when quantities become countable real objects whose physical scale is the evidence.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: quantities, inequality, accumulation, and public-facing data stories

## Signature Features

- One physical unit equals one stated quantity.
- Materials and scale remain consistent.
- Studio product lighting and shallow depth.
- Camera moves from individual unit to total installation.

## Style Prompt

Create a polished visual narrative in the **Data Physicalization** style. Define the unit before showing growth, assemble real-looking plates, blocks, coins, or bars to accurate scale, and let edge markings preserve numerical credibility. Pull back only when the audience understands what each object counts.

## Avoid

- Choose **Animated Data Growth** for conventional charts, or **Narrative Data Drawing** for hand-drawn explanatory annotation.
- Metaphorical objects with no unit, false proportions, decorative piles, generic 3D charts, or numbers added after the fact.
