# Origami Transformation

## Overview

A single sheet becomes forms through explicit folds, creases, and reversals.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: change, compression, hidden structure, and sequential transformation

## Signature Features

- One continuous paper surface.
- Creases define every transformation.
- Facets remain planar.
- Folding sequence is physically understandable.

## Style Prompt

Create a polished HTML animation in the **Origami Transformation** style. Show each fold with a clear hinge and temporary crease highlight, then settle before the next transformation.

## Avoid

- Melting morphs, impossible topology, crumpled paper, cloth-like bending, or cuts that break continuity.
