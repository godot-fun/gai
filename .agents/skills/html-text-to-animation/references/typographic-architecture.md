# Typographic Architecture

## Overview

Words become beams, columns, floors, and supports so a final statement can literally stand on the language that prepared it. Choose this when letters become stable monumental space for a manifesto, climax, or final line.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: closing lines, manifestos, and memorable spoken conclusions

## Signature Features

- Every word has a structural role.
- Earlier phrases support later phrases.
- Final line resolves the construction.

## Style Prompt

Create a polished visual narrative in the **Typographic Architecture** style. Assign semantic weight to position and orientation, assemble the sentence as a stable structure, and land the decisive phrase only after its supports are visible.

## Avoid

- Choose **Impact Typography** when words should hit and disappear rather than become an inhabitable structure.
