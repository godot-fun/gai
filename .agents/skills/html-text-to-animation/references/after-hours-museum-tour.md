# After-Hours Museum Tour

## Overview

A single visitor crosses pitch-dark galleries where isolated spotlights reveal artifacts, wall labels, dioramas, and typed docent commentary with reverent pacing.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Near-black rooms and one hanging warm spotlight per exhibit
- Low-poly or sculptural artifact on pedestal
- Cream museum label with concise provenance
- Visitor silhouette connecting rooms
- Bottom docent-caption bar typing measured commentary

## Style Prompt

Design a connected nighttime gallery route and keep a single visitor moving from room to room so scale and continuity remain clear. Hold architecture in near-black and isolate each exhibit with one warm hanging spotlight. Place a distinct artifact, model, specimen, or diorama on a pedestal and accompany it with a cream wall label containing title, date or category, material, and one concise interpretive note. Type a docent caption slowly along the bottom, but let it add context rather than duplicate the label. Move the camera at walking pace, pausing as the visitor enters a light pool and looks. Use restrained dust, soft floor reflections, and warm sepia highlights while preserving darkness between exhibits. Build a thematic progression and end on the most revealing object or a view linking earlier rooms.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

product-demo spin tables, bright ambient galleries, many spotlights per object, tiny labels, generic artifact repeats, fast transitions, theatrical fog, and captions that overwhelm the exhibit.
