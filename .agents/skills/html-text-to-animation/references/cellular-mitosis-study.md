# Cellular Mitosis Study

## Overview

One cell duplicates, aligns, separates, and divides through clearly staged mitotic phases.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: growth, reproduction, education, and ordered biological change

## Signature Features

- Frame one cell in a restrained microscopy field; differentiate membrane, chromosomes, spindle, and poles with a small consistent palette.
- Progress through prophase, metaphase, anaphase, telophase, and cytokinesis with holds at each checkpoint; keep the cell centered and scale stable.
- Use concise phase labels and a timeline in a neutral scientific sans serif.
