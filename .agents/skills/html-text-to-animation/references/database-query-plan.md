# Database Query Plan

## Overview

Rows flow through scans, joins, filters, sorts, and aggregates while cost concentrates at expensive operators.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: databases, optimization, pipelines, and technical explanation

## Signature Features

- Arrange operators as a directed tree with row estimates, actual rows, cost, and data flow width.
- Stream rows through scans, filters, joins, sorts, and aggregates; let the bottleneck emerge from measured volume and waiting.
- For **Database Query Plan**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.
