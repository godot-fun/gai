# Animated Data Growth

## Overview

Bars, values, and a connecting line appear in reading order so the audience discovers the conclusion with the chart. Choose this for bars, values, and lines revealed in chart-reading order to establish a quantitative conclusion.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: data explanation, research findings, progress, and comparison
- Complexity: Moderate

## Signature Features

- The baseline and scale remain stable and honest.
- Bars grow sequentially while values count toward their final numbers.
- A line or annotation appears only after the underlying values are established.

## Style Prompt

Create a polished HTML animation in the **Animated Data Growth** style. Introduce the title and units first, grow one value at a time, then draw the connecting trend and emphasize the decisive point with one accent. Keep labels readable and preserve accurate proportions.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining behavior above and keep all supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject matter, on-screen wording, duration, aspect ratio, typeface, and accent color.
- Rendering may use HTML, CSS, SVG, Canvas, or WebGL according to the needs of the effect.

## Avoid

- Choose **Data Physicalization** for object-based evidence, or **Narrative Data Drawing** for authored sketch explanation.
- Invented data, misleading axes, decorative 3D charts, simultaneous reveals, unlabeled values, or animation that changes the meaning of the data.
- Do not reproduce historical sample copy or hard-coded layouts from the source material.
- Do not sacrifice readability for motion density.
