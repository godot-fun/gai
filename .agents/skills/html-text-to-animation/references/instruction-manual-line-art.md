# Instruction Manual Line Art

## Overview

Minimal monochrome drawings communicate actions with the directness of a well-designed assembly manual.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: steps, procedures, setup, and safety instruction

## Signature Features

- Uniform economical line work.
- Consistent object viewpoint.
- Hands and arrows show action.
- Numbered sequence hierarchy.

## Style Prompt

Create a polished HTML animation in the **Instruction Manual Line Art** style. Show one action per frame, keep objects spatially consistent, and use arrows only when motion cannot be inferred from pose.

## Avoid

- Decorative shading, expressive backgrounds, ambiguous hand positions, too many arrows, or skipped intermediate states.
