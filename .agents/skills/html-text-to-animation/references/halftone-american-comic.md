# Halftone American Comic

## Overview

Heavy contour, halftone dots, speed lines, and hard contrast create confrontational comic energy. Choose this for heavy contour, dramatic foreshortening, speed lines, and printed halftone action.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: satire, conflict, exaggerated claims, and ironic salesmanship

## Signature Features

- Heavy black contour.
- CMYK-like spot colors.
- Halftone shadow fields.
- Diagonal action and speed accents.

## Style Prompt

Create a polished HTML animation in the **Halftone American Comic** style. Use a dramatic panel crop, one exaggerated action, and a limited print palette. Animate with panel slams, dot-pattern wipes, and short speed-line bursts.

## Avoid

- Choose **Clear-Line Comic** for calm precision, or **Pop Art Comic** for poster-like emphasis rather than sequential action.
- Photoreal rendering, soft gradients, delicate line art, constant impact effects, or full-spectrum color.
