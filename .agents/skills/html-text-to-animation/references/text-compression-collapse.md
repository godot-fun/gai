# Text Compression Collapse

## Overview

Repeated phrases fold into tokens, dictionaries, and references before expanding back into readable language.

## Metadata

- Collection: Typography and Language Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: data, repetition, summaries, encoding, and information density

## Signature Features

- Show repeated phrases, token dictionaries, back-references, and compressed streams as a reversible information structure.
- Identify repetition, replace it with references, display size reduction honestly, then decode in exact reverse order.
- For **Text Compression Collapse**, build hierarchy from the writing system itself: baseline, spacing, glyph anatomy, reading direction, and linguistic timing take precedence over illustration.
