# Formal Proof Lecture

## Overview

A dark textbook-like argument proceeds through numbered lemmas, restrained diagrams, term-by-term equations, citations, and a final therefore statement with QED.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Best for: A dark textbook-like argument proceeds through numbered lemmas, restrained diagrams, term-by-term equations, citations, and a final therefore statement with QED.

## Signature Features

- Near-black panel and faint off-center glow
- Numbered lemma for each claim
- Thin bar, scatter, line, or geometric diagrams
- Color-coded equations assembled term by term
- Closing therefore statement and QED mark

## Style Prompt

Structure the material as a formal proof. State the proposition first, list only the assumptions required, then devote one screen or region to each numbered lemma. On a near-black static field with a faint off-center glow, use clean typography, thin-stroke diagrams, and a restrained color system in which each variable or concept keeps the same hue throughout. Build equations one term at a time and animate a chart only when it supplies evidence for the current lemma. Place small dim citations or source notes in a consistent corner. At each step, explicitly connect the result to the next claim rather than merely presenting facts. Conclude by combining the lemmas into one therefore statement and place a QED mark only if the claim has actually been established. Maintain a steady metronomic rhythm and no camera movement.

## Avoid

decorative particles, dramatic zooms, unsupported assumptions, color changing meanings, dense algebra without explanation, citations too small to inspect, flashy transitions, and using proof language for a persuasive claim that is not logically demonstrated.
