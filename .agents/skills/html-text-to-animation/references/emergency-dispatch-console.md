# Emergency Dispatch Console

## Overview

Calls become prioritized incidents, mapped units, routes, and changing response states.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: public safety, triage, coordination, and time-critical stories
- Complexity: Moderate to advanced

## Signature Features

- Prioritize an incident list beside a clear local map, unit status board, response clock, and one active call transcript area.
- Convert calls into incidents, assign the nearest appropriate unit, update en route and arrival states, and escalate only from evidence.
- For **Emergency Dispatch Console**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Emergency Dispatch Console** style. Prioritize an incident list beside a clear local map, unit status board, response clock, and one active call transcript area. Convert calls into incidents, assign the nearest appropriate unit, update en route and arrival states, and escalate only from evidence. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

Adapt subject matter, wording, duration, and aspect ratio to the user's material. Preserve supplied text unless rewriting is requested, and simplify secondary detail before compromising the defining construction logic.

## Customizable Elements

- Adjust scenario, data density, update cadence, annotation depth, alert severity, and the balance between overview and inspection.
- Change layout, status palette, map or graph scale, and viewpoint without breaking units, chronology, topology, or state semantics.

## Avoid

- Avoid sensational red flashing, identifiable private data, gamified casualties, or units teleporting between incidents.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
- Keep essential text outside dense movement and preserve a clear reduced-motion end state.
