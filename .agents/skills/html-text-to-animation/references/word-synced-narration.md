# Word-Synced Narration

## Overview

A clean typographic track follows spoken language word by word while real images drift slowly behind it. Choose this when every spoken phrase or word must remain aligned to explanatory voice-over and readable as prose.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: voice-led essays, explainers, and accessible narration

## Signature Features

- Captions align to actual speech.
- One type family and clear hierarchy.
- Background imagery moves slowly.

## Style Prompt

Create a polished visual narrative in the **Word-Synced Narration** style. Group words into readable semantic phrases, emphasize only key terms, and let image changes support rather than compete with the voice.

## Avoid

- Choose **Lyric Beat Typography** for songs, or **Phonetic Wave Typography** when sound articulation rather than lexical timing is the subject.
