# News Brief Roundup

## Overview

A recurring news format moves through short items, giving each one a headline, evidence, and a concise reason to care. Choose this for a paced sequence of several independent headlines with consistent cards and short transitions.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: weekly updates, industry roundups, and multi-item summaries

## Signature Features

- Consistent item grammar.
- One verified hook per story.
- Clear progress through the rundown.

## Style Prompt

Create a polished visual narrative in the **News Brief Roundup** style. Open with the rundown, give every item the same headline-evidence-context structure, and use packaging to orient rather than sensationalize.

## Avoid

- Choose **Urgent News Broadcast** when one event deserves continuous live attention.
