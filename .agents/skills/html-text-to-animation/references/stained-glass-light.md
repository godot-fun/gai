# Stained-Glass Light

## Overview

A medieval stained-glass window inside a dark stone hall comes alive only where moving sunlight reaches it. Choose this when lead cames, colored transparent panes, and projected transmitted light define the scene.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: sacred history, allegory, time, and luminous transformation

## Signature Features

- Lead cames define every color field.
- Jewel-toned glass remains translucent.
- Stone interior stays dark.
- Sun position controls narrative visibility.

## Style Prompt

Create a polished visual narrative in the **Stained-Glass Light** style. Let a beam travel across the window, illuminating panels in sequence and projecting colored light onto stone. Use the changing light as clock, camera cue, and story transition.

## Avoid

- Choose **Glass Mosaic Assembly** for opaque mortar-bound tesserae, or **Gothic Stained-Glass Narrative** for explicitly narrative medieval glazing.
- Backlit neon panels, borderless color shapes, fantasy particles, uniformly bright glass, or free-floating camera spectacle.
