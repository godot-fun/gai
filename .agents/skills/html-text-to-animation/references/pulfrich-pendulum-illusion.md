# Pulfrich Pendulum Illusion

## Overview

A laterally swinging object appears to travel through depth when one eye receives a delayed, darker image.

## Metadata

- Collection: Motion Styles
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: binocular timing, perception demonstrations, and apparent-depth motion

## Signature Features

- The physical path remains a flat left-to-right oscillation.
- A controlled delay between eye channels creates the perceived elliptical path.
- Side-by-side diagrams distinguish actual motion from apparent depth.

## Style Prompt

Create a polished HTML animation in the **Pulfrich Pendulum Illusion** style. Establish a pendulum moving in one frontal plane, then introduce a darkened delayed eye channel and trace the depth path that the observer infers. Keep actual position, delayed position, and perceived trajectory visually distinct, with measured restrained motion and no decorative stereoscopic effects.

## Avoid

- Avoid moving the pendulum physically toward the camera, applying equal delay to both eyes, using random parallax, or presenting the illusion without explaining the channel offset.
