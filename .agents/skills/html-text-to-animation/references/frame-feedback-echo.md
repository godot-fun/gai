# Frame-Feedback Echo

## Overview

Each frame re-enters the next through scale, rotation, or displacement, leaving recursive visual trails.

## Metadata

- Collection: Experimental Camera and Image Processes
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: repetition, memory, psychedelia, and feedback systems

## Signature Features

- Feed the previous frame back through one consistent scale, rotation, or translation around a visible attractor point.
- Introduce a subject once, let recursive copies decay by opacity and color, then damp the loop before detail becomes mud.
- For **Frame-Feedback Echo**, use a palette, contrast curve, grain structure, and edge behavior native to the named capture or darkroom process.
