# Astronomical Spectroscopy

## Overview

Starlight separates into a spectrum where absorption and emission lines identify composition and motion.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: astronomy, chemical evidence, remote sensing, and cosmic scale
- Complexity: Moderate to advanced

## Signature Features

- Place a small astronomical source beside an expanded spectrum on black; render wavelength position accurately and keep absorption or emission lines narrow.
- Pass light through a slit and disperser, build the spectrum from photons, then shift or compare lines without moving their reference scale.
- Use crisp white scientific typography, wavelength ticks, and sparse element labels in matching line colors.
