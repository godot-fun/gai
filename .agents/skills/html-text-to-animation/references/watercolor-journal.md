# Watercolor Journal

## Overview

A warm cotton-paper journal paints itself with translucent washes, dry-brush gaps, and handwritten observation. Choose this for dated field notes, sketches, labels, and observational watercolor accumulated like a travel diary.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: travel, nature, memory, and reflective field notes

## Signature Features

- Transparent layered washes.
- Dry-brush flying white.
- Handwritten marginal notes.
- No vector contour around every form.

## Style Prompt

Create a polished visual narrative in the **Watercolor Journal** style. Let broad washes establish atmosphere, then add a few confident brush details and concise notes beside—not over—the image. Preserve unpainted paper as light.

## Avoid

- Choose **Watercolor Illustration** for a standalone image without journal structure.
- Opaque digital fill, uniform wet edges, traced vector outlines, saturated gradients, or handwriting used as texture.
