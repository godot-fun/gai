# Footnote Cascade

## Overview

Superscript references open into nested notes whose depth and return paths remain navigable.

## Metadata

- Collection: Typography and Language Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: context, scholarship, caveats, and branching explanation
- Complexity: Moderate to advanced

## Signature Features

- Use clear superscript anchors, numbered notes, nested depth limits, and visible return paths between body and annotation.
- Open one note at a time, indent nested references, then collapse back to the originating line before continuing.
- For **Footnote Cascade**, build hierarchy from the writing system itself: baseline, spacing, glyph anatomy, reading direction, and linguistic timing take precedence over illustration.

## Style Prompt

Create a polished HTML animation in the **Footnote Cascade** style. Use clear superscript anchors, numbered notes, nested depth limits, and visible return paths between body and annotation. Open one note at a time, indent nested references, then collapse back to the originating line before continuing. Build hierarchy from glyph anatomy, spacing, reading direction, linguistic timing, and the specific encoding or word structure being demonstrated. Limit color to paper or screen neutrals plus one semantic accent; keep every required character readable at the intended viewing distance. Let reading order, linguistic structure, or encoding rules determine transitions instead of applying generic kinetic-type presets.

Adapt duration, aspect ratio, hierarchy, and annotation without changing supplied wording. Verify every character, pronunciation, encoding, and reading convention used by the effect.

## Customizable Elements

- Adjust type family, scale, spacing, line length, pacing, annotation depth, and the balance between primary reading and structural explanation.
- Change typographic scale, neutral surface, accent color, and motion amplitude while preserving valid glyphs, reading order, timing, and decodability.

## Avoid

- Avoid unbounded recursion, modal pop-up clutter, missing anchors, tiny unreadable notes, or notes that become the main narrative accidentally.
- Do not invent characters, pronunciations, encodings, reading conventions, or linguistic relationships to complete the composition.
- Keep essential text readable and provide a stable reduced-motion state that preserves the final composition.
