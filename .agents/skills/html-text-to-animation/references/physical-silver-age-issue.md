# Physical Silver-Age Comic Issue

## Overview

A portrait comic book is read on camera through cover, page turns, panel pushes, splash pages, and a colophon back cover.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Physical portrait book centered in a dark landscape frame
- Two-page spreads and varied panel grids
- Flat red, gold, blue, black, and Ben-Day texture
- Speech-bubble guide, sound bursts, and sunburst fields
- Camera pans and pushes within pages rather than replacing them

## Style Prompt

Stage a real portrait-format comic book against a near-black vignette. Open on an original magazine-style cover with issue information and a strong title, then turn through several spreads. Use a clear panel grid as a base but vary it with one splash or border-breaking moment. Build art from flat red, gold-orange, blue, black, and paper white, adding Ben-Day screens, sunbursts, thick ink, dialogue balloons, narration boxes, and hand-drawn sound bursts. Let an original mascot or guide recur in speech bubbles without becoming a copied superhero. Keep the book itself visible during most transitions. Pan and push into individual panels like a motion-comic documentary, animate only small internal actions, then pull back before the page turn. Close on a colophon-like back cover that resolves the message.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

full-screen scenes that forget the book, identical two-by-two spreads, copied issue branding, excessive dialogue, glossy gradients, smooth character animation, and camera moves that cross gutters without reorientation.
