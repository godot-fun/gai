# Eastern Poetic Landscape

## Overview

Moonlight, water, pavilions, mist, and restrained interaction translate classical poetic space into a living web scene.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: cultural openings, poetry, mood, and contemplative interaction

## Signature Features

- Layered depth through mist and water.
- Sparse classical architecture.
- Interaction remains quiet and symbolic.

## Style Prompt

Create a polished visual narrative in the **Eastern Poetic Landscape** style. Use asymmetrical balance, long pauses, and subtle environmental response; let text, seal, or moon act as a single focal accent rather than filling the scene with motifs.

## Avoid

- Avoid generic pan-Asian ornament, crowded motifs, restless interaction, or using classical symbols without contextual relevance.
