# Breathing Particle Sphere

## Overview

A soft cloud of particles expands and contracts with a slow respiratory rhythm. Choose this for one cohesive meditative volume governed by a slow inhale–exhale cycle.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: grounding, meditation, reassurance, and moments that need to slow down

## Signature Features

- One coherent volume controls the composition.
- Expansion, rest, contraction, and rest form a readable breath cycle.
- Individual particles drift subtly without breaking the shared form.

## Style Prompt

Create a polished HTML animation in the **Breathing Particle Sphere** style. Center a restrained particle cloud on a quiet field. Use long ease-in-out breathing cycles, a slight luminance lift during expansion, and a short still point at each extreme.

## Avoid

- Choose **Particle Shape Morph** for changing silhouettes, **Magnetic Particle Field** for force visualization, or **Flow-Field Particle Formation** for directional currents.
- Fast pulsing, medical UI decoration, many colors, dramatic camera motion, or particles escaping the breathing form.
