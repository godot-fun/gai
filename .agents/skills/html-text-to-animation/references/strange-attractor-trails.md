# Strange-Attractor Trails

## Overview

Thousands of trajectories orbit an invisible chaotic attractor, exposing order inside apparent instability.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: chaos, sensitivity, complex systems, uncertainty, and invisible forces

## Signature Features

- Persistent trails cluster around a mathematically coherent attractor without ever closing into a simple loop.
- Build density gradually, shift viewpoint sparingly, and use fading history to reveal recurring lobes.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.

## Style Prompt

Create a polished HTML animation in the **Strange-Attractor Trails** style. Thousands of trajectories orbit an invisible chaotic attractor, exposing order inside apparent instability. Use composition, timing, color, and camera behavior to make the governing mechanism understandable before adding secondary detail.

## Avoid

- random scribbles, equal-density fog, rapid camera spins, or trajectories with no shared dynamical center.
- Do not reproduce historical sample copy or hard-coded layouts from source material.
- Do not sacrifice readability for procedural complexity.
