# Supershape Morphology

## Overview

A single parametric equation morphs between stars, petals, cells, and crystalline silhouettes.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: classification, design exploration, morphology, and continuous transformation

## Signature Features

- All forms emerge from continuous changes to a small visible parameter set rather than unrelated path swaps.
- Interpolate parameters with measured holds at distinctive forms and show subtle guides when explanation matters.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.

## Style Prompt

Create a polished HTML animation in the **Supershape Morphology** style. A single parametric equation morphs between stars, petals, cells, and crystalline silhouettes. Use composition, timing, color, and camera behavior to make the governing mechanism understandable before adding secondary detail.

## Avoid

- hard cuts between silhouettes, shapeless wobble, too many simultaneous parameters, or fake biological certainty.
- Do not reproduce historical sample copy or hard-coded layouts from source material.
- Do not sacrifice readability for procedural complexity.
