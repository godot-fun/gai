# Pixel-Sprite 3D Diorama

## Overview

Handmade pixel sprites stand like paper cutouts inside a fogged, lamp-lit 3D world viewed through a tilt-shift lens. Choose this when flat pixel sprites inhabit a visibly dimensional miniature set with camera parallax.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, WebGL, or generated visual assets
- Best for: fantasy travel, emotional game scenes, and dimensional pixel storytelling
- Complexity: Advanced

## Signature Features

- Crisp flat pixel sprites.
- Physical 3D sets and shadows.
- High three-quarter camera.
- Fog and tilt-shift depth.
