# Building-Block System

## Overview

Interlocking toy-like blocks make modular construction and dependency visually obvious.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: systems assembled from parts, learning, architecture, and product stacks

## Signature Features

- Standardized modular units.
- Visible studs or connectors.
- Color-coded functions.
- Stepwise physical assembly.

## Style Prompt

Create a polished HTML animation in the **Building-Block System** style. Add modules in causal order, show connections clearly, and use exploded spacing before the final lock-in.

## Avoid

- Direct branded toy imitation, impossible connections, many decorative colors, soft clay deformation, or instantaneous assembly.
