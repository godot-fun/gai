# Silkscreen Travel Poster

## Overview

Four to six opaque inks build a destination poster one hard-edged color pass at a time.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: places, events, tourism, and bold environmental storytelling
- Complexity: Advanced

## Signature Features

- Opaque spot-color layers.
- Stepped bands replace gradients.
- Thin paper gaps reveal slight registration slip.
- Each print pass is one narrative beat.

## Style Prompt

Create a polished visual narrative in the **Silkscreen Travel Poster** style. Reduce the destination to iconic silhouettes and a compact palette, then reveal inks in print order from broad ground to type and final accent.

Translate the user's material into this visual grammar rather than copying source examples. Preserve supplied wording, evidence, and attribution; select an implementation appropriate to the material.

## Customizable Elements

- Subject, copy, duration, aspect ratio, pacing, palette emphasis, and implementation method.

## Avoid

- Transparent Risograph mixing, photographic skies, soft digital gradients, too many colors, or registration error that destroys edges.
- Never invent documents, measurements, quotations, sources, or factual evidence.
- Do not use surface effects as a substitute for narrative structure.
