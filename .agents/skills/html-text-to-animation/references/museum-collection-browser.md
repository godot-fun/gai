# Museum Collection Browser

## Overview

Objects reorganize by time, place, material, creator, and relationship in an exploratory curatorial interface.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: culture, archives, taxonomy, and discovery
- Complexity: Moderate to advanced

## Signature Features

- Use generous archival cards, object photography zones, accession metadata, filters, and a stable comparison tray.
- Recluster objects by one selected facet at a time while preserving object identity and enabling a clear return path.
- For **Museum Collection Browser**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Museum Collection Browser** style. Use generous archival cards, object photography zones, accession metadata, filters, and a stable comparison tray. Recluster objects by one selected facet at a time while preserving object identity and enabling a clear return path. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

Adapt subject matter, wording, duration, and aspect ratio to the user's material. Preserve supplied text unless rewriting is requested, and simplify secondary detail before compromising the defining construction logic.

## Customizable Elements

- Adjust scenario, data density, update cadence, annotation depth, alert severity, and the balance between overview and inspection.
- Change layout, status palette, map or graph scale, and viewpoint without breaking units, chronology, topology, or state semantics.

## Avoid

- Avoid Pinterest-like masonry chaos, decorative dates, mixing metadata fields, or movement that loses the selected object.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
- Keep essential text outside dense movement and preserve a clear reduced-motion end state.
