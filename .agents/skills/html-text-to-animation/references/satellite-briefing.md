# Satellite Briefing

## Overview

Real satellite imagery is graded into an analyst's field and measured with sparse ground-locked instruments.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: geography, change detection, conflict analysis, climate, and infrastructure

## Signature Features

- One continuous orbit-to-ground zoom.
- Thin white measurement graphics.
- A single lock-on, outline, range, or reading at a time.
- Time may advance inside a locked view.

## Style Prompt

Create a polished visual narrative in the **Satellite Briefing** style. Use stacked real imagery plates for a continuous scale change, dim color to neutral grey, and attach measurements to actual terrain. Let the same framing compare time states before returning to geographic context.

## Avoid

- Fictional satellite detail, sci-fi HUD clutter, free-floating labels, too many readings, or dramatic targeting aesthetics without analytical purpose.
