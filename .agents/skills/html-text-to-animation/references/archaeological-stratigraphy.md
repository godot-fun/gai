# Archaeological Stratigraphy

## Overview

A site section accumulates deposits and artifacts in chronological layers before excavation reverses the sequence.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: history, excavation, provenance, and temporal reasoning

## Signature Features

- Show a precise soil section with interfaces, cuts, fills, features, and artifacts positioned by context; use restrained earth pigments and drawing conventions.
- Accumulate deposits chronologically, then excavate them in reverse while preserving context numbers; use a fixed sectional camera with occasional detail inset.
- Use archival field labels, context numbers, and fine leader lines in dark ink.
