# Swiss Motion Graphics

## Overview

International Typographic Style becomes motion through a modular grid, one type family, one signal color, and press-like precision.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: information design, cultural programs, research, and authoritative modern titles

## Signature Features

- Strict modular grid.
- One sans-serif family with disciplined scale.
- One signal color.
- Motion preserves baseline and alignment logic.

## Style Prompt

Create a polished visual narrative in the **Swiss Motion Graphics** style. Let rules, type, and blocks enter as exact grid operations: align, crop, reorder, and lock. Use asymmetry deliberately and make every transition improve information structure.

## Avoid

- Decorative geometry, multiple display fonts, soft floating motion, rounded cards, or effects that ignore the grid.
