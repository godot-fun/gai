# Volumetric Fog Projection

## Overview

Projected light becomes sculptural inside suspended fog, revealing cones, planes, and moving voids.

## Metadata

- Collection: Light and Optical Materials
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: atmosphere, concerts, spatial diagrams, and mysterious reveals

## Signature Features

- Define a black room with layered haze and a small number of sharp light planes, cones, or scanned lines; retain dark negative volumes between beams.
- Animate projectors rather than the fog, allowing geometry to intersect and reveal depth; use a slow dolly through the light with cautious contrast.
- Use wide, sparse type on an independent foreground plane so beam scatter never destroys legibility.

## Style Prompt

Create a polished HTML animation in the **Volumetric Fog Projection** style. Define a black room with layered haze and a small number of sharp light planes, cones, or scanned lines; retain dark negative volumes between beams. Animate projectors rather than the fog, allowing geometry to intersect and reveal depth; use a slow dolly through the light with cautious contrast. Use wide, sparse type on an independent foreground plane so beam scatter never destroys legibility. Make every transition arise from the optical or scientific process itself, and preserve enough negative space for the supplied message to remain primary.

## Avoid

- Avoid cloud simulation without projectors, excessive smoke billows, rainbow concert clutter, rapid strobes, or beams visible outside the fog volume.
