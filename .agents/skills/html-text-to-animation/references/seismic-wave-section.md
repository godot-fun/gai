# Seismic Wave Section

## Overview

Pulses travel through layered earth, reflect at boundaries, and return as aligned traces that reveal buried structure.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: geology, earthquakes, exploration, and indirect measurement

## Signature Features

- Stack geological layers in a clean cross-section with sources, receivers, and interfaces; reserve distinct line styles for P, S, and reflected paths.
- Fire one pulse, propagate wavefronts at layer-dependent speeds, reflect and refract them at boundaries, then align returning traces into a seismogram.
- Use technical sans-serif labels, depth scales, and restrained earth tones with one signal accent.
