# Enamel Pin Collection

## Overview

Small outlined emblems fill with hard enamel, polish to a gloss, and arrange into a collectible visual taxonomy.

## Metadata

- Collection: Print, Textile and Physical Craft
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: badges, milestones, communities, and playful classification

## Signature Features

- Design small die-struck metal outlines with recessed color cells, polished raised edges, clasps, and a curated backing card.
- Stamp the outline, fill enamel by cell, cure and polish, then place pins into a meaningful taxonomy.
- For **Enamel Pin Collection**, let tool marks, joins, surface response, and small process variation provide material truth; choose colors plausible for the named craft.

## Style Prompt

Create a polished HTML animation in the **Enamel Pin Collection** style. Design small die-struck metal outlines with recessed color cells, polished raised edges, clasps, and a curated backing card. Stamp the outline, fill enamel by cell, cure and polish, then place pins into a meaningful taxonomy. Use typography only where the process naturally permits it—as printed matter, labels, annotations, or adjacent editorial framing. Organize the message around the making sequence so every texture, seam, impression, cut, or color layer has a visible physical cause.

## Avoid

- Avoid flat sticker icons, borderless color, rubbery surfaces, random badge clouds, or every pin using the same silhouette.
- Do not apply craft texture as a surface filter; show how tools, pressure, fibers, joins, or pigment actually produce it.
