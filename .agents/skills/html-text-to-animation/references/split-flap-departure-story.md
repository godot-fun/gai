# Split-Flap Departure Story

## Overview

A railway-style mechanical board narrates through clattering character tiles, amber indicators, station time, row-by-row updates, and authentic pauses.

## Signature Features

- Dark modular tile matrix with central split
- Sequential alphabet or symbol cycling
- Amber lamps and mechanical station clock
- Row labels, destinations, times, platforms, and statuses
- Sound and motion decelerate as each message locks

## Style Prompt

Build a physical split-flap board from repeated dark modules, each with a visible horizontal split, hinge depth, and slight surface wear. Organize information into believable rows such as time, destination, subject, platform, status, or metric. When a row changes, cycle each tile through its allowed alphabet or number set at a slightly different phase, beginning rapidly and decelerating until the target message locks. Let longer changes propagate across the row rather than flipping every tile identically. Add small amber status lamps and a station clock whose second hand or minute flip provides continuous time. Use camera framing that reveals both whole-board information and close mechanical detail. Synchronize clatter and final clicks without making every row noisy at once.

## Avoid

smooth rotating cubes, unsupported fonts over tiles, instant text replacement, random letters that violate the character set, identical phase across all modules, excessive neon, unreadable dense schedules, and clock behavior unrelated to elapsed time.
