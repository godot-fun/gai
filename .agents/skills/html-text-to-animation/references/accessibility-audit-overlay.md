# Accessibility Audit Overlay

## Overview

A live interface receives focus paths, contrast checks, semantic labels, and issue markers without losing context.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: inclusive design, QA, interfaces, and remediation
- Complexity: Moderate to advanced

## Signature Features

- Retain the real interface hierarchy while adding focus order, semantic roles, contrast ratios, target sizes, and issue severity.
- Walk keyboard focus through the page, reveal one issue class at a time, then show the corrected state without hiding context.
- For **Accessibility Audit Overlay**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Accessibility Audit Overlay** style. Retain the real interface hierarchy while adding focus order, semantic roles, contrast ratios, target sizes, and issue severity. Walk keyboard focus through the page, reveal one issue class at a time, then show the corrected state without hiding context. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

Adapt subject matter, wording, duration, and aspect ratio to the user's material. Preserve supplied text unless rewriting is requested, and simplify secondary detail before compromising the defining construction logic.

## Customizable Elements

- Adjust scenario, data density, update cadence, annotation depth, alert severity, and the balance between overview and inspection.
- Change layout, status palette, map or graph scale, and viewpoint without breaking units, chronology, topology, or state semantics.

## Avoid

- Avoid painting everything red, cursor-only testing, invented compliance claims, or overlay labels that block the element being audited.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
- Keep essential text outside dense movement and preserve a clear reduced-motion end state.
