# Animated Ukiyo-e

## Overview

An Edo woodblock print comes alive through carved line, flat color, bokashi gradation, and paper-aware camera movement.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: landscape, folklore, travel, weather, and stylized historical narrative

## Signature Features

- Carved key lines control the image.
- Flat registered color blocks.
- Bokashi gradation appears as print craft.
- Camera glides like an unfolding handscroll.

## Style Prompt

Create a polished visual narrative in the **Animated Ukiyo-e** style. Animate within print logic: waves repeat, cloth shifts, clouds advance, and the viewpoint travels laterally across the composed sheet. Preserve limited color and visible paper grain.

## Avoid

- Anime rendering, smooth airbrushed gradients, photoreal depth, floating particles, or direct copying of a known print.
