# Study Notebook

## Overview

Underlines, sticky notes, arrows, and margin comments organize information like a thoughtful student's notebook.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: methods, lists, study guides, and personal workflows

## Signature Features

- Ruled or dotted paper.
- Layered handwriting and neat body text.
- Sticky-note callouts.
- Circles, arrows, and highlighted phrases.

## Style Prompt

Create a polished HTML animation in the **Study Notebook** style. Reveal the page in reading order, add annotations only after the base note appears, and use a limited highlighter palette.

## Avoid

- Scrapbook clutter, illegible handwriting, decorative stickers everywhere, or annotations with no hierarchy.
