# Organized Flat Lay

## Overview

Objects are arranged from directly above into a precise, satisfying visual inventory.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: toolkits, ingredients, collections, and process preparation

## Signature Features

- True overhead viewpoint.
- Even spacing and deliberate alignment.
- Clear object categories.
- Controlled surface texture.

## Style Prompt

Create a polished HTML animation in the **Organized Flat Lay** style. Introduce items by category, slide them into a final ordered arrangement, and use labels sparingly at the margins.

## Avoid

- Oblique camera angles, overlapping clutter, arbitrary rotation, harsh perspective, or labels covering objects.
