# Causal UI Morph Loop

## Overview

One persistent interface control becomes an entire product journey—button, loader, media, slider, tabs, chart, palette, toast, and button—under direct cursor manipulation.

## Metadata

- Collection: Code Video Styles

## Signature Features

- No scene cut and one persistent geometric identity
- Cursor click, drag, hover, and selection cause every state
- Matched corners, anchors, color roles, and topology
- Beat-aligned but functionally credible timing
- Final state reconnects seamlessly to the opening

## Style Prompt

Choose one compact interface element and preserve a recognizable anchor, corner radius, color, or icon through every transformation. Let a visible cursor initiate all changes: click the button, which closes into a loader; expand it into a player; drag the timeline into a slider; split it into tabs; turn selected tabs into chart bars; open those bars into a command palette; confirm an item into a toast; compress the toast back into the starting control. Plan intermediate geometry so boundaries, text baselines, and icons travel continuously instead of cross-fading. Land key states on beats but allow enough dwell for their interaction to read. Keep pointer behavior believable and visual hierarchy consistent. Hide no cuts behind full-screen flashes. Design the final collapse so the next opening click loops exactly.

## Avoid

arbitrary morph order, impossible cursor actions, labels warping unreadably, UI from unrelated design systems, topology popping, decorative charts, and a loop whose first and last frames merely resemble rather than match.
