# Diagrammatic Lyric Video

## Overview

A technical explainer synchronized to an instrumental track, where every lyric line becomes one diagram and appears as readable on-screen text rather than sung audio.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Best for: A technical explainer synchronized to an instrumental track, where every lyric line becomes one diagram and appears as readable on-screen text rather than sung audio.

## Signature Features

- Dark engineering grid
- Persistent section label
- One diagram per lyric line
- Current line set clearly along the bottom
- Instrumental rhythm drives diagram construction

## Style Prompt

Divide the song into clear sections and assign each a small persistent corner label. Use a dark grid as the common stage and design exactly one dominant diagram for each lyric line: process flow, orbit, comparison, stack, waveform, map, timeline, force diagram, or transformation. Display the current lyric along the bottom with careful line breaks and highlight words only when their visual counterpart changes. Build each diagram on the musical phrase through strokes, nodes, labels, counters, and simple geometric movement, then simplify or clear it before the next line. Let the instrumental carry melody and rhythm; do not synthesize a sung voice unless explicitly requested. Establish a recurring visual motif so separate diagrams feel like one song. Keep notation readable and literal enough to teach, but poetic enough to reward the lyric.

## Avoid

karaoke bouncing on every syllable, several diagrams at once, tiny labels, unrelated music visualizers, full-screen prose, vocals contradicting displayed text, and cuts that miss musical phrasing.
