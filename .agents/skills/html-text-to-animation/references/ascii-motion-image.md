# ASCII Motion Image

## Overview

A visible character grid becomes an image, echoing the warmth and limits of an old computer display. Choose this when a character grid gradually resolves into a warm low-resolution moving picture without requiring a simulated terminal interface.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: technology, cold memory, fragmented identity, and retro-computing atmosphere
- Complexity: Moderate

## Signature Features

- Monospaced characters encode brightness and form.
- The grid remains visible as a material, not merely an effect.
- Image and readable text can transform into each other.

## Style Prompt

Create a polished HTML animation in the **ASCII Motion Image** style. Use a strict monospaced grid, a dark near-black field, and one phosphor-like amber or green color family. Animate density waves, scans, or a moving light source while preserving crisp cell alignment.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining behavior above and keep all supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject matter, on-screen wording, duration, aspect ratio, typeface, and accent color.
- Rendering may use HTML, CSS, SVG, Canvas, or WebGL according to the needs of the effect.

## Avoid

- Choose **ASCII CRT Terminal** when every form lives inside an authentic phosphor terminal, or **Green Phosphor Command Story** when commands drive the narrative.
- Random character soup, proportional fonts, rainbow terminal colors, excessive interface chrome, or a grid too fine to read.
- Do not reproduce historical sample copy or hard-coded layouts from the source material.
- Do not sacrifice readability for motion density.
