# Sunset 3D Epigraph

## Overview

A slow 3D flight through purple clouds, sunset light, and reflected water carries one short emotional line.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: peak emotional statements, endings, and contemplative transitions

## Signature Features

- One cinematic environment.
- Slow continuous camera.
- One concise line of text.

## Style Prompt

Create a polished visual narrative in the **Sunset 3D Epigraph** style. Build toward the line through light and scale, place it only after the environment has established mood, and hold without adding secondary messages.

## Avoid

- Avoid multiple competing quotations, rapid camera motion, constant lens effects, or placing the epigraph before the environment earns it.
