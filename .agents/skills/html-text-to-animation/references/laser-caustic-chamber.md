# Laser-Caustic Chamber

## Overview

Narrow beams pass through curved transparent forms and focus into sharp moving caustic lines.

## Metadata

- Collection: Light and Optical Materials
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: precision, optics, discovery, and high-energy transitions

## Signature Features

- Place one refractive object inside a black optical chamber; render a narrow source beam, precise entry and exit rays, and a bright folded caustic on a matte surface.
- Sweep the beam or rotate the optic by a few degrees so the caustic migrates continuously; keep the camera locked until a final oblique reveal.
- Use technical sans-serif labels connected by fine leader lines, with no text inside the brightest caustic.
