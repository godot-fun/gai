# Crayon Picture Book

## Overview

Wax-crayon marks are drawn live on toothy paper, then watercolor reveals forms resisted by the wax.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: children's stories, innocence, learning, and tender memory

## Signature Features

- Visible wax drag and broken coverage.
- Toothy paper catches the crayon.
- Watercolor resist creates the reveal.
- Simple child-readable staging.

## Style Prompt

Create a polished visual narrative in the **Crayon Picture Book** style. Draw a small set of bold crayon shapes in sequence, wash translucent color across them, and let the hidden white marks emerge. Keep gestures direct and page composition generous.

## Avoid

- Vector-perfect lines, glossy digital brushes, dense adult detail, many wet effects, or childish clutter with no story.
