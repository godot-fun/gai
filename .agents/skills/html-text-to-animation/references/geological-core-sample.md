# Geological Core Sample

## Overview

A cylindrical core rotates and opens into labeled strata, fossils, fractures, and chronological depth.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: deep time, resources, evidence, and layered history

## Signature Features

- Place a cylindrical core beside an unrolled stratigraphic column; use mineral earth tones, fractures, grain changes, and measured depth marks.
- Rotate the core, split it longitudinally, and scan downward at a constant rate while correlating each segment to the flat log.
- Use field-note sans serif, specimen IDs, depth numbers, and sparse leader lines.
