# Constellation Relationship Network

## Overview

A field of stars connects into a social map while one warm node becomes the emotional center.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: relationships, belonging, loneliness, influence, and social structure
- Complexity: Moderate

## Signature Features

- Nodes form sparse meaningful clusters.
- Links appear only when a relationship matters.
- One warm focal node contrasts with a cooler network.

## Style Prompt

Create a polished HTML animation in the **Constellation Relationship Network** style. Reveal the network causally: introduce nodes, draw selected links, then trace the path that reaches or isolates the focal point. Keep labels selective and preserve dark breathing room between clusters.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining behavior above and keep all supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject matter, on-screen wording, duration, aspect ratio, typeface, and accent color.
- Rendering may use HTML, CSS, SVG, Canvas, or WebGL according to the needs of the effect.

## Avoid

- Hairball graphs, links between every node, constant pulsing, equal visual weight, or labels covering the network.
- Do not reproduce historical sample copy or hard-coded layouts from the source material.
- Do not sacrifice readability for motion density.
