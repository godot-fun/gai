# Scenario Forecast Branches

## Overview

A shared present divides into conditional futures whose assumptions, ranges, and decision points remain comparable.

## Metadata

- Collection: Economics, Markets and Business Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: forecasts, assumptions, uncertainty, alternative futures, and decision making

## Signature Features

- Begin every branch from the same observed baseline and label the assumption that causes each divergence.
- Show ranges, confidence, thresholds, and update points instead of presenting single precise endpoints.
- Keep scenarios comparable through aligned time, units, metrics, and visual scale.

## Style Prompt

Create a polished HTML animation in the **Scenario Forecast Branches** style. Establish a sourced present on a horizontal time axis, then branch only when a named assumption, shock, or decision changes. Expand each future into a bounded range, mark thresholds and reversible decisions, and allow new evidence to prune or reshape branches. Preserve common scales so viewers can compare outcomes without mistaking scenarios for predictions.

## Avoid

- Avoid unlabeled optimism-versus-pessimism lines, false precision, or probabilities that do not sum coherently.
- Do not conceal assumptions, mix incompatible horizons, or imply that the widest visual branch is most likely.
