# Signal Interruption

## Overview

Brief image displacement and color separation interrupt an otherwise stable message.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: breakdown, confusion, denial, interruption, and unreliable communication
- Complexity: Moderate

## Signature Features

- A clean baseline makes each fault noticeable.
- Glitches occur in short semantic bursts.
- Slice displacement, channel separation, and dropout serve distinct roles.

## Style Prompt

Create a polished HTML animation in the **Signal Interruption** style. Establish a readable stable frame, trigger brief faults on emotionally fractured words, then restore clarity. Use horizontal slices, restrained red-cyan separation, scan dropout, and one secondary reveal that exposes what the stable statement conceals.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining behavior above and keep all supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject matter, on-screen wording, duration, aspect ratio, typeface, and accent color.
- Rendering may use HTML, CSS, SVG, Canvas, or WebGL according to the needs of the effect.

## Avoid

- Continuous random noise, flashing on every frame, unreadable text, many neon colors, seizure-risk strobing, or glitches with no narrative trigger.
- Do not reproduce historical sample copy or hard-coded layouts from the source material.
- Do not sacrifice readability for motion density.
