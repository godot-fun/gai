# Liminal Found Footage

## Overview

Recovered camcorder tapes explore empty fluorescent spaces where posted rules create more fear than visible monsters.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, WebGL, or generated visual assets
- Best for: uncanny architecture, procedural horror, isolation, and implied threat

## Signature Features

- Ordinary empty transitional spaces.
- Consumer camcorder limitations.
- Rules establish danger.
- Threat remains mostly outside the frame.
