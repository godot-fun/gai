# Anamorphic Room Illusion

## Overview

Distorted fragments align into one coherent image only from a precisely chosen viewpoint.

## Metadata

- Collection: Architecture and Spatial Installation
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: perspective, hidden messages, revelation, and spatial puzzles

## Signature Features

- Distribute one distorted graphic across walls, floor, and objects so it aligns only from a marked observation point.
- Begin off-axis with fragments, move precisely to the solution view, hold the coherent image, then depart to expose distortion.
- For **Anamorphic Room Illusion**, choose a restrained architectural palette led by material color and one light or wayfinding accent; preserve human scale and believable structure.

## Style Prompt

Create a polished HTML animation in the **Anamorphic Room Illusion** style. Distribute one distorted graphic across walls, floor, and objects so it aligns only from a marked observation point. Begin off-axis with fragments, move precisely to the solution view, hold the coherent image, then depart to expose distortion. Choose a restrained palette led by structural material, environmental light, and one wayfinding or performance accent; preserve human scale. Use quiet modernist typography on plans, plaques, or negative space, never as weightless decoration inside the built volume. Organize the message around spatial sequence, structural behavior, or installation mechanics so every transformation remains inhabitable and legible.

## Avoid

- Avoid simple perspective text on one plane, crossfades at alignment, arbitrary camera paths, or an illusion readable from every angle.
- Do not add architectural detail that ignores structure, circulation, material span, installation mechanics, or human scale.
