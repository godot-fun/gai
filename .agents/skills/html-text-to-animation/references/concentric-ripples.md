# Concentric Ripples

## Overview

A single drop sends rings outward, making influence and aftermath visible.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: the impact of a sentence, consequence, resonance, and emotional aftershocks

## Signature Features

- Every wave has a clear initiating point.
- Ring spacing and fading communicate propagation.
- A calm surface makes each disturbance meaningful.

## Style Prompt

Create a polished HTML animation in the **Concentric Ripples** style. Begin in near stillness, introduce one precise impact, then expand thin rings with gentle decay. If multiple impacts are needed, sequence them causally and let intersections show interaction without obscuring the field.

## Avoid

- Continuous random ripples, photoreal water spectacle, heavy distortion, simultaneous impacts everywhere, or rings with no narrative source.
