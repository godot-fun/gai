# Single-Line Landscape

## Overview

One continuous stroke gradually draws a landscape, a sun, and a solitary figure. Choose this for a quiet scene drawn as one continuous environmental contour with minimal narrative branching.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: personal journeys, simple biographies, process explanations, and quiet reflection

## Signature Features

- A continuous line is the main visual actor.
- Drawing order reveals the scene as a story.
- The completed image remains spare and readable.

## Style Prompt

Create a polished HTML animation in the **Single-Line Landscape** style. Plan a path that is meaningful while it is being drawn, not only at completion. Vary speed around curves and landmarks, pause at the human figure, and use a single restrained accent if needed.

## Avoid

- Choose **Single-Line Narrative** for sequential story beats, or **Continuous-Line Morph** when the line must transform subjects.
- Aimless scribbling, dense cross-hatching, many disconnected paths, uniform draw speed, or labels that crowd the line.
