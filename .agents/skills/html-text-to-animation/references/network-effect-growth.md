# Network-Effect Growth

## Overview

Participation changes the value of a network as users, creators, buyers, sellers, or complementary groups join and interact.

## Metadata

- Collection: Economics, Markets and Business Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: platforms, marketplaces, adoption loops, and compounding participation

## Signature Features

- Distinguish same-side, cross-side, local, and data effects through different link behaviors.
- Tie perceived value to useful interactions, liquidity, coverage, or match quality rather than node count alone.
- Reveal congestion, cold-start friction, moderation cost, and saturation alongside positive feedback.

## Style Prompt

Create a polished HTML animation in the **Network-Effect Growth** style. Grow one or more participant groups around a persistent interaction network, adding links only when plausible exchanges occur. Let match rate, coverage, response time, or content value improve as participation changes, while exposing cold-start gaps and eventual congestion. Use consistent node roles and make the reinforcing loop spatially and causally legible.

## Avoid

- Avoid treating viral acquisition, economies of scale, and network effects as synonyms.
- Do not draw a glowing complete graph or assume that every additional user increases value equally.
