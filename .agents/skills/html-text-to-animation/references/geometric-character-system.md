# Geometric Character System

## Overview

Circles, rectangles, and triangles assemble into characters and objects with structural clarity.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: systems, roles, organization, and modular explanation

## Signature Features

- Primitive shapes remain recognizable.
- Consistent modular proportions.
- Color identifies function.
- Assembly and disassembly drive motion.

## Style Prompt

Create a polished HTML animation in the **Geometric Character System** style. Build subjects visibly from reusable components and animate relationships through grouping, alignment, and exchange.

## Avoid

- Organic painterly forms, arbitrary decoration, too many primitives, or transformations that hide structure.
