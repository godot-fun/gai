# Pixel Art

## Overview

Deliberate block pixels and a limited palette evoke classic game graphics without losing compositional clarity. Choose this as the general pixel grammar: deliberate grid, limited palette, hard edges, and sprite-like economy without a required narrative format.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: retro games, playful systems, and nostalgic storytelling

## Signature Features

- Fixed visible pixel grid.
- Limited indexed palette.
- Clustered pixel shapes.
- Frame-stepped animation.

## Style Prompt

Create a polished HTML animation in the **Pixel Art** style. Choose a consistent virtual resolution, design clean pixel clusters, and animate on deliberate frame holds with readable silhouettes.

## Avoid

- Choose **16-Bit Console RPG** for full RPG conventions, **Pixel-Sprite 3D Diorama** for dimensional staging, or **Top-Down Pixel Neon City** for an urban overhead world.
- Mixed pixel sizes, anti-aliasing, smooth vector motion, excessive colors, or high-resolution detail disguised by a pixel filter.
