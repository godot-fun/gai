# Window Light and Dust

## Overview

A single shaft of daylight reveals drifting dust and the quiet passage of time.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: stillness, old rooms, contemplation, and gentle remembrance
- Complexity: Moderate

## Signature Features

- One directional beam structures the frame.
- Dust is visible primarily inside the light volume.
- Brightness changes almost imperceptibly.

## Style Prompt

Create a polished HTML animation in the **Window Light and Dust** style. Use a warm oblique beam against neutral shadow, matte surfaces, and sparse slow particles. Place text at the edge of the light or within its calm center and keep the camera locked.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining behavior above and keep all supplied text unchanged unless rewriting is requested.

- Do not reproduce historical sample copy or hard-coded layouts from the source material.
