# Election Results Wall

## Overview

Verified counts fill districts, seats, and proportional bars while uncertainty and reporting progress stay visible.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: elections, live reporting, geography, and public data

## Signature Features

- Combine a restrained district map, seat totals, reporting percentage, verified vote counts, and uncertainty indicators.
- Update only from reported batches, distinguish projected from confirmed states, and preserve previous totals for auditability.
- For **Election Results Wall**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Election Results Wall** style. Combine a restrained district map, seat totals, reporting percentage, verified vote counts, and uncertainty indicators. Update only from reported batches, distinguish projected from confirmed states, and preserve previous totals for auditability. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

## Avoid

- Avoid horse-race confetti, premature calls, unlabeled color scales, or silently changing denominators.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
