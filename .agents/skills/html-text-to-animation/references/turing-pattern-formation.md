# Turing Pattern Formation

## Overview

A uniform field destabilizes into spots, stripes, and labyrinths through activator–inhibitor interaction.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: morphogenesis, pattern formation, biological explanation, and emergence

## Signature Features

- Local activation and longer-range inhibition create coherent motifs from tiny initial variation.
- Begin nearly uniform, amplify subtle differences, and hold on the mature pattern before transitioning.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.
