# Biennale Yellow

## Overview

An art-biennial editorial cover built from parchment, indigo rules, monumental serif type, and one solar-yellow disc.

## Metadata

- Collection: Ready-Made Layouts
- Medium: HTML, CSS, SVG, or Canvas
- Best for: cultural titles, essays, exhibitions, and refined opening cards
- Complexity: Moderate

## Signature Features

- Warm parchment ground with subtle printed grain.
- Indigo typography and hairline rules.
- One large yellow sun used as the sole accent.
- Asymmetric magazine-cover hierarchy.

## Style Prompt

Create a polished HTML animation in the **Biennale Yellow** style. Use a framed editorial grid, oversized two-line serif title, fine header and footer metadata, and a slowly rising sun with restrained orbital detail. Animate rules drawing on, then type and metadata settling into place.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Sans-serif hero type, multiple accent colors, glassmorphism, rounded cards, particles, or heavy shadow.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
