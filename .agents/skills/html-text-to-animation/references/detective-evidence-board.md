# Detective Evidence Board

## Overview

A lamp-lit corkboard accumulates pinned evidence and taut red thread around one unknown subject before a single flash reveals the resolved identification.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Warm cork, pins, cards, notes, photos, and labels
- Central unknown-subject card
- Red thread added only after related evidence appears
- One continuous lateral camera investigation
- Single camera-flash cut to a stamped resolution card

## Style Prompt

Build a coherent physical corkboard under one warm desk lamp. Start from a central unknown-subject card and gradually add index cards, photographs, maps, receipts, timestamps, handwritten notes, and small evidence bags around it. Each item must contribute a distinct fact. Pin an item first, allow it to be read, then stretch a taut red thread from it to the appropriate card; do not pre-fill the board with meaningless connections. Travel in one continuous pan or side-track across the surface, occasionally pushing closer to handwriting or a photo while maintaining spatial orientation. Accumulate toward a wide conspiracy-board view in which the network is readable. Use one and only one hard transition: a camera-flash whiteout that swaps the central mystery card for a clean identification or conclusion card and stamps the case state.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

multiple flash cuts, random props, thread crossing everything, illegible handwriting, unsupported accusations, floating digital cards, horror lighting, and a reveal not earned by the displayed evidence.
