# Creative Mode

## Overview

A joyful cream-ground layout with saturated candy shapes and heavyweight grotesk lettering.

## Metadata

- Collection: Ready-Made Layouts
- Medium: HTML, CSS, SVG, or Canvas
- Best for: creative tools, playful launches, workshops, and optimistic explainers
- Complexity: Moderate

## Signature Features

- Cream base with a compact saturated palette.
- Heavy black headline type.
- Simple shapes used as active punctuation.
- Playful but disciplined grid.

## Style Prompt

Create a polished HTML animation in the **Creative Mode** style. Let bold type arrive first, then use colored shapes to underline, bracket, and transition between ideas. Keep movement crisp and graphic rather than toy-like.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Rainbow overload, childish stickers, weak hierarchy, soft shadows, or shapes moving without relation to the text.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
