# Cinematic Anime

## Overview

Clean line art, designed hair shapes, expressive eyes, and strong shot composition create a dramatic animated-cinema language. Choose this for a contemporary, medium-neutral anime cinema language with polished shot design and unrestricted modern rendering.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: emotion, action, coming-of-age, and cinematic character moments

## Signature Features

- Clean selective line art.
- Graphic cel-shadow shapes.
- Expressive controlled facial acting.
- Purposeful cinematic framing.

## Style Prompt

Create a polished HTML animation in the **Cinematic Anime** style. Prioritize shot design, silhouette, and emotional timing over constant movement. Use limited animation, atmospheric depth, and decisive close-ups.

## Avoid

- Choose **1980s Cel Anime** when painted cels, airbrushed backgrounds, limited-animation timing, and CRT-era texture are essential.
- Generic fan-art posing, excessive eye sparkle, random speed lines, photoreal skin, or constant camera motion.
