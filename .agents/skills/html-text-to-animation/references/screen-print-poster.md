# Screen-Print Poster

## Overview

Flat spot colors, visible registration shifts, and ink texture create a tactile designed print. Choose this when spot-color layers, ink texture, and slight registration shift must reveal the physical printing method.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: posters, cultural events, bold chapter cards, and graphic illustration

## Signature Features

- Two to four spot colors.
- Slight intentional misregistration.
- Flat opaque shapes.
- Visible ink and paper grain.

## Style Prompt

Create a polished HTML animation in the **Screen-Print Poster** style. Separate the image into clear color passes and animate them printing or sliding into registration. Keep overlaps meaningful and preserve bold silhouettes.

## Avoid

- Choose **Coral Condensed Poster** for clean flat typography, or **Silkscreen Travel Poster** for place-based scenic illustration.
- Full-spectrum gradients, photographic smoothness, random offset on every frame, glossy surfaces, or too many fine lines.
