# Digital Twin Dashboard

## Overview

A live spatial model mirrors sensor state, operational metrics, alerts, and predicted maintenance.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: industry, infrastructure, simulation, and monitoring

## Signature Features

- Pair a restrained spatial model with live sensor cards, operating ranges, maintenance state, and simulation confidence.
- Update sensors at believable cadence, highlight deviations at their physical location, and compare prediction with observed state.
- For **Digital Twin Dashboard**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Digital Twin Dashboard** style. Pair a restrained spatial model with live sensor cards, operating ranges, maintenance state, and simulation confidence. Update sensors at believable cadence, highlight deviations at their physical location, and compare prediction with observed state. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

## Avoid

- Avoid a glossy 3D model disconnected from data, omniscient forecasts, constant camera orbit, or alerts with no thresholds.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
