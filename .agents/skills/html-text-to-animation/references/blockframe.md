# BlockFrame

## Overview

A neo-brutalist layout of thick black frames, hard shadows, and sharp candy-color inserts.

## Metadata

- Collection: Ready-Made Layouts
- Medium: HTML, CSS, SVG, or Canvas
- Best for: bold explainers, product statements, provocative claims, and energetic title cards
- Complexity: Moderate

## Signature Features

- Heavy black outlines and visibly boxed regions.
- Offset hard shadows with no blur.
- Flat cream ground plus saturated candy accents.
- Large condensed or grotesk typography.

## Style Prompt

Create a polished HTML animation in the **BlockFrame** style. Build the frame from rigid blocks that snap, slide, and stack on a coarse grid. Let borders and shadows remain graphic objects; use abrupt but readable transitions and reserve the brightest block for the current statement.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Soft gradients, subtle shadows, delicate ornament, rounded UI cards, or loose alignment.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
