# Papyrus Scroll Chronicle

## Overview

Horizontal fiber strips, ink columns, seals, and rolling reveals turn reading into a physical journey.

## Metadata

- Collection: Print, Textile and Physical Craft
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: ancient history, proclamations, journeys, and records

## Signature Features

- Build horizontal fiber texture, column-based ink writing, wooden rollers, seals, and worn exposed edges.
- Unroll only enough for the current passage, move reading column by column, and reroll the completed section.
- For **Papyrus Scroll Chronicle**, let tool marks, joins, surface response, and small process variation provide material truth; choose colors plausible for the named craft.
