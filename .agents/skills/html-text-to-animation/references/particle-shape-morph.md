# Particle Shape Morph

## Overview

A single population of particles gathers into meaningful silhouettes, disperses, and flows into the next form. Choose this when one particle population repeatedly assembles into recognizable silhouettes and disperses between them.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: home, relationships, identity, assembly, and transformation

## Signature Features

- The same particles visibly travel between target shapes.
- Each silhouette receives a readable settled hold.
- Curved transition paths create expansion before reconvergence.

## Style Prompt

Create a polished HTML animation in the **Particle Shape Morph** style. Move through a clear cycle of settle, hold, release, arcing transition, and reform. Keep target shapes simple, preserve particle identity across transitions, use deterministic variation, and let captions appear only during stable holds.

## Avoid

- Choose **Breathing Particle Sphere** for one stable volume, or **Typographic Dissolve and Reform** when the transformed subjects are specifically statements.
- Flash explosions, random respawning, rainbow palettes, illegible silhouettes, or state changes that snap without visible travel.
