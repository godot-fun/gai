# Animated Art Deco

## Overview

Black lacquer, engraved gold, airbrushed geometry, and central symmetry create a moving 1930s luxury poster.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: luxury, architecture, nightlife, ceremony, and glamorous openings

## Signature Features

- Strong central axis.
- Gold line on black lacquer.
- Stepped fans, rays, and geometric frames.
- Light arrives as sequential bulbs.

## Style Prompt

Create a polished visual narrative in the **Animated Art Deco** style. Open and close transitions along the center axis, reveal gold structures with controlled sweeps, and use light bulbs or marquee points to build toward a symmetrical hero frame.

## Avoid

- Generic Gatsby props, excessive glitter, asymmetrical clutter, many colors, or chrome 3D text.
