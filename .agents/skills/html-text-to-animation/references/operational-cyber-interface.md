# Operational Cyber Interface

## Overview

A fictional interface that behaves like a coherent instrument: layered grids, target tracking, waveform evidence, and stateful data tied to one mission.

## Metadata

- Collection: Motion Graphics Styles
- Medium: Cinematic HTML animation
- Best for: A fictional interface that behaves like a coherent instrument: layered grids, target tracking, waveform evidence, and stateful data tied to one mission.

## Signature Features

- Dark field with restrained cyan, amber, red, or green status colors
- Modular panels, reticles, scales, maps, and traces
- Primary target always anchored to visible evidence
- Scan, acquire, analyze, confirm, and resolve state sequence
- Fine typography and micro-motion subordinate to the main readout

## Style Prompt

Design the interface around one concrete operational task from the user's content. Establish a dark spatial field, a disciplined grid, and a limited luminous palette with one status color per meaning. Organize information into a clear hierarchy: primary target or object, supporting map or spatial view, one waveform or timeline, numerical evidence, system state, and a small action log. Every reticle, leader, coordinate, and graph must attach to real visible data. Animate in logical states: boot or scan, detection, acquisition, deeper analysis, warning or uncertainty, confirmation, and final resolved frame. Let panels slide or unfold only when their data becomes relevant; use subtle sweeps, ticking numbers, and cursor travel as background motion. Keep fine lines crisp, glow tight, and labels concise.

## Avoid

decorative nonsense numbers, unrelated charts, every panel moving at once, illegible microtype, rainbow neon, permanent alarm red, opaque windows covering the subject, and interface frames copied from an existing franchise.
