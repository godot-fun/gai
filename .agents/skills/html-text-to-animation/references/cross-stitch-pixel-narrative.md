# Cross-Stitch Pixel Narrative

## Overview

Counted X-shaped stitches assemble a gridded image one color region at a time.

## Metadata

- Collection: Print, Textile and Physical Craft
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: pixel-like stories, patience, folk craft, and modular imagery

## Signature Features

- Keep an explicit counted fabric grid with diagonal thread pairs, a limited floss palette, and slight handmade variation.
- Complete each X in a consistent order, work color regions methodically, and reveal the image through accumulated stitches.
- For **Cross-Stitch Pixel Narrative**, let tool marks, joins, surface response, and small process variation provide material truth; choose colors plausible for the named craft.

## Avoid

- Avoid square pixels instead of crossed thread, stitches between holes, unlimited gradients, or instant region fills.
- Do not apply craft texture as a surface filter; show how tools, pressure, fibers, joins, or pigment actually produce it.
