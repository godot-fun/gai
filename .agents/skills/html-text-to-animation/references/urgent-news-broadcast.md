# Urgent News Broadcast

## Overview

A complete cable-news package moves from globe stinger to anchor, geolocation, data cards, and closing ident under persistent live broadcast chrome. Choose this for a single rapidly developing event with live status, escalation, and time-critical hierarchy.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Deep navy, hard red, white, and restrained secondary blue
- Globe title and diagonal tri-color stinger
- Illustrated anchor desk with persistent lower third
- World-to-country-to-city map zoom
- Always-visible clock, channel bug, and scrolling ticker

## Style Prompt

Create an original channel identity and treat the sequence as a live breaking update. Open with a rotating globe and restrained title reveal, then sweep a diagonal navy-red-white ribbon across frame to introduce the headline. Cut to a flat-vector anchor at a desk with persistent lower third, live clock, channel bug, and a ticker carrying genuinely relevant short updates. Push into a map through world, country or region, city, and one precise pin, then alternate the anchor with only the most important data cards. Use condensed numerals, bold hierarchy, hard-edged transitions, and constant but disciplined on-screen information. Maintain urgent pacing without sacrificing comprehension. Return to the anchor or close on a minimal channel ident once the update is resolved.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

- Choose **News Brief Roundup** for multiple concise stories, or **Caption News** when silent viewing is the primary constraint.
