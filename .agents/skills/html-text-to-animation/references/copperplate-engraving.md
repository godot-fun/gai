# Copperplate Engraving

## Overview

A burin cuts swelling lines into copper before a proof builds through outline, hatching, cross-hatching, and engraved lettering.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: historical portraiture, scientific plates, maps, and meticulous archival explanation

## Signature Features

- Pressure-sensitive engraved line.
- Form develops from outline to cross-hatching.
- Proof-pull transition reveals the plate.
- Magnified details expose line craft.

## Style Prompt

Create a polished visual narrative in the **Copperplate Engraving** style. Show the burin establishing contours, deepen tone with organized hatching, pull a paper proof, and add labels or a restrained hand wash only after the engraved structure is complete.

## Avoid

- Woodcut gouges, uniform digital lines, random cross-hatching, instant antique filters, or color hiding the engraving.
