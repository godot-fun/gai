# Firefly Light Dust

## Overview

Warm points of light drift upward at different depths, suggesting memory and recovered hope.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: warm recollection, intimacy, wonder, and finding light again

## Signature Features

- Sparse lights have varied size, focus, and depth.
- Movement rises slowly with gentle lateral drift.
- Brightness flickers independently and reserves one collective reveal.

## Style Prompt

Create a polished HTML animation in the **Firefly Light Dust** style. Keep most of the frame dark and quiet. Use a single warm gold family, shallow depth cues, and loose clusters that guide attention toward the text without surrounding every element.

## Avoid

- Dense starfields, fireworks, snowfall motion, uniform pulsing, or multiple neon colors.
