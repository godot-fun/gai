# Radio Telescope Interferometry

## Overview

Signals from separated dishes combine across baselines to sharpen a faint celestial source.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: collaboration, astronomy, synthesis, and distributed measurement

## Signature Features

- Arrange separated dishes on a geographic baseline diagram with a shared target and synchronized signal paths; use cool night neutrals and one timing accent.
- Rotate Earth or advance observation time so projected baselines change, combine phase-aligned signals, and progressively sharpen the reconstructed image.
- Use compact technical labels, clocks, and baseline values in a restrained monospaced face.
