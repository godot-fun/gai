# Delaunay Mesh Transformation

## Overview

A responsive triangulation reorganizes itself as anchor points move, making structural adaptation visible.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: networks, responsive systems, optimization, and changing relationships

## Signature Features

- Non-overlapping Delaunay triangles connect a shared set of moving points and visibly flip edges when topology changes.
- Move a few anchors along clear paths and emphasize each legal edge flip as the mesh rebalances.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.
