# Kanban Workflow Choreography

## Overview

Work cards cross constrained stages while queues, blockers, and throughput emerge over time.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: projects, bottlenecks, teams, and continuous delivery
- Complexity: Moderate to advanced

## Signature Features

- Keep a small number of named columns, visible work-in-progress limits, aged cards, blockers, and throughput markers.
- Pull cards rather than pushing them, pause at constrained columns, unblock explicitly, and reveal queue growth over time.
- For **Kanban Workflow Choreography**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Kanban Workflow Choreography** style. Keep a small number of named columns, visible work-in-progress limits, aged cards, blockers, and throughput markers. Pull cards rather than pushing them, pause at constrained columns, unblock explicitly, and reveal queue growth over time. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

Adapt subject matter, wording, duration, and aspect ratio to the user's material. Preserve supplied text unless rewriting is requested, and simplify secondary detail before compromising the defining construction logic.

## Customizable Elements

- Adjust scenario, data density, update cadence, annotation depth, alert severity, and the balance between overview and inspection.
- Change layout, status palette, map or graph scale, and viewpoint without breaking units, chronology, topology, or state semantics.

## Avoid

- Avoid cards flying continuously, unlimited columns, hidden WIP limits, or treating motion itself as productivity.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
- Keep essential text outside dense movement and preserve a clear reduced-motion end state.
