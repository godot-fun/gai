# Continuous Scene Morph

## Overview

The entire film unfolds without a visible cut as each environment grows from the geometry of the previous one.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: transformation, progress, and before-to-after stories

## Signature Features

- No hard cuts.
- Shared shapes bridge scenes.
- Camera path remains spatially coherent.

## Style Prompt

Create a polished visual narrative in the **Continuous Scene Morph** style. Plan transitions around common contours, surfaces, or motions, keep the camera moving with purpose, and give each scene a readable hold before it becomes the next.

## Avoid

- Avoid hidden hard cuts, unrelated shape substitutions, incoherent camera jumps, or morphs that never pause as readable scenes.
