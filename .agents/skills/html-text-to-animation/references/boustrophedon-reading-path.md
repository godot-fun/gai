# Boustrophedon Reading Path

## Overview

Alternating text lines reverse direction like a plowing path, with orientation cues preserving legibility.

## Metadata

- Collection: Typography and Language Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: ancient writing, journeys, alternation, and unconventional reading
- Complexity: Moderate to advanced

## Signature Features

- Alternate line direction on a clearly ruled field and transform glyph orientation only according to the chosen historical convention.
- Guide the eye with a restrained turn at each line end, pausing long enough for reverse-direction reading.
- For **Boustrophedon Reading Path**, build hierarchy from the writing system itself: baseline, spacing, glyph anatomy, reading direction, and linguistic timing take precedence over illustration.
