# Live Sports Stat Match

## Overview

A night-stadium broadcast package turns a head-to-head comparison into score bug, player cards, stat sheets, momentum shifts, and a confetti-timed final result.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Floodlit stadium and LED-dot crowd
- Persistent score bug, LIVE badge, and source ticker
- Hard-cut chapters with locked camera
- Counting numerals, filling bars, sliding cards, and glow accents
- Analytical quiet beat before a bright finale

## Style Prompt

Frame two options, teams, products, or approaches as opponents in an original live-sports package. Establish a night stadium with floodlights and an LED-dot crowd, then maintain a compact score bug, LIVE badge, and a source or context ticker. Divide the comparison into short hard-cut chapters: introduction cards, category-by-category stats, one detailed analytical sheet, momentum swing, and final result. Keep camera fixed within each card while numerals count, bars fill, cards slide, and restrained glows identify the leader. Cite units and sources visibly enough to prevent sport styling from disguising weak data. Pull energy down during the analytical chapter, then rebuild toward a winner or draw with confetti and a clear summary.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

fake live framing for stale data, real league branding, arbitrary scores, cheering that implies unsupported superiority, constant camera moves, bars with inconsistent scales, nonstop glow, and a final winner not justified by shown categories.
