# Fourier Epicycle Drawing

## Overview

Rotating circles of decreasing size combine into a traveling point that reconstructs a line drawing.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: signal decomposition, reconstruction, sound, mathematics, and complexity from simple waves

## Signature Features

- Each epicycle attaches to the previous radius and the final tip alone traces the target contour.
- Add circles from largest contribution to smallest, then follow the tip while the reconstructed path persists.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.
