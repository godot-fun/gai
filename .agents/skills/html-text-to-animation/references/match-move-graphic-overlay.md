# Match-Move Graphic Overlay

## Overview

Graphic labels and geometry remain locked to moving real-world surfaces through perspective-aware tracking.

## Metadata

- Collection: Experimental Camera and Image Processes
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: explainers, products, sports, and augmented evidence

## Signature Features

- Track real planar or spatial features so labels, grids, measurements, and highlights inherit perspective, occlusion, and motion blur.
- Establish the shot before graphics enter, lock each overlay to a defensible feature, and let foreground objects occlude it correctly.
- For **Match-Move Graphic Overlay**, use a palette, contrast curve, grain structure, and edge behavior native to the named capture or darkroom process.

## Avoid

- Avoid screen-space labels that drift, no occlusion, over-tracked decoration, excessive HUD elements, or measurements without reference points.
- Do not imitate a photographic, optical, or compression process with unrelated glitch decoration or a generic color filter.
