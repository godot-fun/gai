# Abstract Emotion Visualization

## Overview

Shape, type, color, spacing, and motion express a feeling without relying on literal characters or objects.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: anxiety, fear, uncertainty, longing, and conceptual passages
- Complexity: Moderate to advanced

## Signature Features

- Formal choices map to emotional qualities.
- No literal illustrative shortcut.
- Motion evolves with the feeling.

## Style Prompt

Create a polished visual narrative in the **Abstract Emotion Visualization** style. Choose a small visual vocabulary, assign each property a meaning, and build an emotional arc through pressure, repetition, release, or reorientation.

Adapt the subject, copy, duration, aspect ratio, and implementation method while preserving the defining narrative and motion logic. Keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, copy, duration, aspect ratio, palette, pacing, and implementation method.

## Avoid

- Do not copy sample brands, characters, or wording from the source material.
- Do not add motion that has no explanatory, rhythmic, or emotional purpose.
- Preserve readability and one dominant idea per beat.
