# Persuasive Brand Line Motion

## Overview

A silent official-looking brand explainer that moves from friction to insight to action using a dark field, white drawn line, bold type, and one accent color.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Single dark ground
- Thin white hand-drawn diagrams and scribbled emphasis
- Bold restrained typography
- One brand accent with a defined semantic role
- Pain, reframing, proof, and call-to-action arc

## Style Prompt

Build the sequence as a persuasive argument, not a logo reel. Begin with a concrete friction visualized by one thin white line on a dark field: knot, barrier, overload, loop, gap, or fragmented path. Draw and redraw the line by hand so its imperfections communicate exploration. Introduce short bold statements one at a time and reserve a single accent color for the solution, key metric, or action—never for decoration. Let scribbled circles, arrows, underlines, crossings-out, and brackets focus attention, then transform the original problem diagram into a simpler resolved form. Progress through four beats: problem, changed perspective, visual proof, and one concise call to action. Keep hierarchy strong enough to work silently and hold the final brand frame with subtle line life.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

corporate icon grids, several accent colors, long paragraphs, sound-dependent timing, arbitrary kinetic type, glowing UI, and claims that are not demonstrated by the visual transformation.
