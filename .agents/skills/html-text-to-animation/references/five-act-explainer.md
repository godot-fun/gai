# Five-Act Explainer

## Overview

Five purposeful scenes move from hook to context, mechanism, consequence, and takeaway.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: complete short explainers and compact tool stories

## Signature Features

- Exactly one job per act.
- Escalating information.
- Final act resolves the opening question.

## Style Prompt

Create a polished visual narrative in the **Five-Act Explainer** style. Design a visual question, orient the viewer, demonstrate the core mechanism, show why it matters, and finish with one actionable or memorable line.

## Avoid

- Avoid interchangeable acts, introducing the mechanism before context, or ending without resolving the opening question.
