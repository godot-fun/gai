# Minimal Beat Cuts

## Overview

Each shot communicates one thing with large negative space, one accent color, and a cut precisely on the musical downbeat.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: rapid lists, feature sequences, and rhythmic statements

## Signature Features

- One idea per shot.
- Single accent color.
- Every cut serves the tempo.

## Style Prompt

Create a polished visual narrative in the **Minimal Beat Cuts** style. Reduce each item to one symbol or phrase, preserve a consistent grid, and vary scale and direction while cutting only on meaningful beats.

## Avoid

- Avoid multiple competing ideas per shot, off-beat cutting, gratuitous transitions, or visual density that defeats the minimal grammar.
