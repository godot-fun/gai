# Cellular Automata Evolution

## Overview

A strict grid evolves through local neighbor rules until simple cells reveal surprising collective behavior.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: emergence, population change, contagion, computation, and rule-based systems

## Signature Features

- Discrete cells switch state only from visible neighborhood logic, preserving the grid as the central evidence.
- Advance in countable generations with occasional holds that let the viewer compare cause and consequence.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.

## Style Prompt

Create a polished HTML animation in the **Cellular Automata Evolution** style. A strict grid evolves through local neighbor rules until simple cells reveal surprising collective behavior. Use composition, timing, color, and camera behavior to make the governing mechanism understandable before adding secondary detail.

## Avoid

- smooth particle drift, arbitrary blinking, hidden rules, or decorative grids with no state history.
- Do not reproduce historical sample copy or hard-coded layouts from source material.
- Do not sacrifice readability for procedural complexity.
