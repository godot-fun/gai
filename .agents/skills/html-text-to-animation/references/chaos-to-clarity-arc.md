# Chaos-to-Clarity Arc

## Overview

An entire film moves from visual disorder through control into a clean final statement.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: recovery, organization, problem solving, and emotional resolution

## Signature Features

- Disorder has a designed cause.
- Repeated shapes gradually align.
- Final frame is markedly simpler.

## Style Prompt

Create a polished visual narrative in the **Chaos-to-Clarity Arc** style. Define a measurable progression in density, alignment, palette, and motion; transform recurring forms continuously instead of cutting between unrelated aesthetics.

## Avoid

- Avoid random disorder, an instant cleanup, or a final state that retains the same density and alignment as the opening.
