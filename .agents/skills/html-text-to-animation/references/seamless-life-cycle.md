# Seamless Life Cycle

## Overview

One figure moves from childhood through age and returns seamlessly to the opening state.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: lifelong learning, generations, continuity, and cyclical time

## Signature Features

- Recognizable identity across ages.
- Transitions share pose or gesture.
- Ending loops causally into beginning.

## Style Prompt

Create a polished visual narrative in the **Seamless Life Cycle** style. Select a repeated action or object, age the figure and environment through meaningful milestones, and close on a match that makes the cycle inevitable.

## Avoid

- Avoid arbitrary age jumps, changing identity cues between stages, or a loop that resets mechanically instead of closing through shared action.
