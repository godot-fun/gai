# Used Whiteboard Lecture

## Overview

A fixed desk-camera watches one hand write, draw, revise, underline, circle, and erase a proof or explanation while earlier work remains as ghosted residue. Choose this when erasure ghosts, overwritten notation, and a lecturer's accumulated reasoning are essential.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Physical board, aluminum bezel, markers, and block eraser
- Hand enters consistently from one edge
- Every mark built stroke by stroke
- Numbers and diagrams corrected live
- Palimpsest of faint earlier sections

## Style Prompt

Lock the camera on a physical whiteboard inside its aluminum bezel. Bring one hand in from a consistent lower corner holding a small set of dry-erase colors. Build all words, equations, diagrams, arrows, underlines, and circles in real stroke order at credible hand speed. Organize the board spatially before writing so each new section has room and earlier material can remain. When the reasoning changes, cross out or erase only the affected region, leave realistic grey residue, and write the replacement visibly. Use circled step numbers, one green confirmation mark, and one red concern or exception, keeping the rest dark neutral. Never wipe the board completely; let previous sections ghost beneath the current one as a used palimpsest. Pause after important steps so viewers can read.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

- Choose **Live-Drawn Whiteboard** for a clean first-pass explanation.
floating text without a hand, perfect font-like handwriting, instant diagrams, disappearing old content, impossible arm positions, marker colors changing mid-stroke, excessive doodles, and pacing too fast for comprehension.
