# Projection on a White Model

## Overview

A fixed white massing model becomes a data surface as projected light paints one layer at a time across its geometry.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: urban systems, architecture, environmental data, and scenario comparison
- Complexity: Advanced

## Signature Features

- Unchanging white physical model.
- Dark-room presentation on a plinth.
- Data exists only as projected light.
- Projection respects surface orientation and spills slightly.

## Style Prompt

Create a polished visual narrative in the **Projection on a White Model** style. Keep the model and camera stable while successive data layers illuminate relevant faces, fade, and compare. Use real projection behavior, restrained spill, and a clear legend outside the model.
