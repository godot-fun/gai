# Toon-Shaded 3D

## Overview

Three-dimensional models use hard cel-shadow bands and graphic outlines instead of realistic shading. Choose this when full three-dimensional models use hard cel-shadow bands and graphic outlines rather than visible polygon facets.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: stylized action, game-like explainers, and dimensional diagrams

## Signature Features

- Hard light-shadow separation.
- Controlled outer contour.
- Simplified materials.
- Graphic color blocking.

## Style Prompt

Create a polished HTML animation in the **Toon-Shaded 3D** style. Use 3D depth for staging while keeping surfaces flat and illustrative. Animate camera and character with clear silhouette changes.

## Avoid

- Choose **Low-Poly 3D** when faceting is structural, or **Cinematic Rounded 3D** when soft volumetric lighting should remain visible.
- Soft global illumination, noisy textures, photoreal reflections, outlines on every internal edge, or muddy shadow colors.
