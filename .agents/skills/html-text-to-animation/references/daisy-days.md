# Daisy Days

## Overview

A sunny garden-pastel layout with charcoal outlines, hard offset shadows, and friendly rounded type.

## Metadata

- Collection: Ready-Made Layouts
- Medium: HTML, CSS, SVG, or Canvas
- Best for: family stories, gentle education, wellness, and cheerful seasonal pieces
- Complexity: Moderate

## Signature Features

- Pastel garden palette.
- Three-pixel charcoal outlines.
- Small hard shadows with no blur.
- Rounded approachable lettering.

## Style Prompt

Create a polished HTML animation in the **Daisy Days** style. Build scenes from simple outlined flowers, leaves, suns, and labels. Use short lift-and-settle motions, paper-cut transitions, and buoyant pacing while keeping the composition tidy.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Glossy 3D flowers, neon colors, soft airbrushed shadows, hyperactive bouncing, or overly cute facial features.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
