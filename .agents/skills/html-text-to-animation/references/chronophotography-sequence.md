# Chronophotography Sequence

## Overview

Successive phases of movement share one measured frame, turning time into a readable anatomy of motion.

## Metadata

- Collection: Experimental Camera and Image Processes
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: sports, biomechanics, history, and temporal analysis
- Complexity: Moderate to advanced

## Signature Features

- Use a fixed measured backdrop, one moving subject, interval marks, and overlapping silhouettes with consistent exposure.
- Sample motion at equal time intervals, preserve every phase in one frame or ordered plate, and add a scale or trajectory only when useful.
- For **Chronophotography Sequence**, use a palette, contrast curve, grain structure, and edge behavior native to the named capture or darkroom process.
