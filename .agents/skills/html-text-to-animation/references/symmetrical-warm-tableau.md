# Symmetrical Warm Tableau

## Overview

A centered warm-toned stage observes time passing through small environmental changes and restrained camera movement.

## Metadata

- Collection: Motion Styles
- Medium: HTML animation, SVG, Canvas, WebGL, or composited media
- Best for: reflection, pauses, seasons, travel, and elapsed time

## Signature Features

- Strong bilateral balance.
- Pastel warm production design.
- One stable observational viewpoint.

## Style Prompt

Create a polished visual narrative in the **Symmetrical Warm Tableau** style. Lock the central composition, let seasons, objects, or light change around it, and use symmetry breaking only for the emotional turn.

## Avoid

- Avoid casual symmetry breaks, frequent reframing, harsh palette shifts, or environmental changes too large to preserve the observational viewpoint.
