# Cartesian Editorial

## Overview

A quiet modernist composition of warm paper, ink typography, taupe accents, and fine Cartesian rules. Choose this for quiet analytical composition built from warm paper, fine Cartesian rules, taupe accents, and restrained serif type.

## Metadata

- Collection: Ready-Made Layouts
- Medium: HTML, CSS, SVG, or Canvas
- Best for: thoughtful essays, architecture, systems, and minimal title sequences

## Signature Features

- Large areas of deliberate white space.
- Hairline axes and measured coordinates.
- Ink-black type with muted taupe annotation.
- Restrained asymmetric balance.

## Style Prompt

Create a polished HTML animation in the **Cartesian Editorial** style. Build the composition from an axis, a few plotted alignments, and one strong headline. Animate lines extending and labels finding their coordinates; keep timing slow, exact, and nearly frictionless.

## Avoid

- Choose **Cobalt Grid** when the grid should be bolder and blue, or **Capsule Editorial** for more playful luxury.
- Charts without meaning, bright primary colors, large shadows, decorative grids, or crowded copy.
