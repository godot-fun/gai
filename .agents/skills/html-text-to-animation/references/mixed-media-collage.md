# Mixed-Media Collage

## Overview

Torn paper, photographs, type fragments, and found textures collide in an intentional editorial composition. Choose this for intentionally heterogeneous found photography, torn paper, type fragments, and tactile source contrast.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: complexity, cultural commentary, memory, and layered argument

## Signature Features

- Visible torn and cut edges.
- Mixed photographic and graphic material.
- Scale discontinuity.
- Strong editorial hierarchy.

## Style Prompt

Create a polished HTML animation in the **Mixed-Media Collage** style. Use a limited set of materials, reveal layers through tearing and paste-like placement, and maintain one dominant focal statement per beat.

## Avoid

- Choose **Editorial Cutout Collage** when clean cut silhouettes and magazine hierarchy should dominate.
- Random scrapbook clutter, too many textures, weak hierarchy, soft blended edges, or copyrighted logos used decoratively.
