# Chalkboard Illustration

## Overview

Colored chalk on a dark board combines classroom clarity with handmade warmth.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: teaching, scientific intuition, and step-by-step reasoning

## Signature Features

- Dark matte board.
- Powdery broken chalk strokes.
- White plus a few chalk colors.
- Erasure ghosts and hand-drawn diagrams.

## Style Prompt

Create a polished HTML animation in the **Chalkboard Illustration** style. Draw ideas progressively, reserve color for categories or emphasis, and use partial erasure as a transition between related concepts.

## Avoid

- Neon glow, clean vector lines, too many colors, dense equations without explanation, or glossy black surfaces.
