# Infinity Mirror Corridor

## Overview

Parallel reflective surfaces repeat lights and figures into an apparently endless tunnel.

## Metadata

- Collection: Architecture and Spatial Installation
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: infinity, recursion, spectacle, and self-reflection

## Signature Features

- Align parallel mirrors, evenly spaced lights, dark framing, and a single clear viewing axis with accurate recursive falloff.
- Approach the corridor slowly, let repetitions diminish in brightness and scale, and avoid lateral moves that break the illusion.
- For **Infinity Mirror Corridor**, choose a restrained architectural palette led by material color and one light or wayfinding accent; preserve human scale and believable structure.
