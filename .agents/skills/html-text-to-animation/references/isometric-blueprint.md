# Isometric Blueprint

## Overview

Technical line work and isometric projection explain the internal structure of a tool or system. Choose this for static explanatory isometric line art that exposes the structure of one tool, object, or compact system.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: components, architecture, engineering, and product anatomy

## Signature Features

- Consistent isometric axes.
- Fine construction lines.
- Exploded or assembled components.
- Dimension and callout hierarchy.

## Style Prompt

Create a polished HTML animation in the **Isometric Blueprint** style. Reveal construction geometry first, then assemble components and add concise callouts. Use one blueprint color family and one status accent.

## Avoid

- Choose **Living Blueprint** for drafting-order animation, **Cyanotype Engineering Drama** for photographic cyanotype material, or **Blueprint-to-Golden 3D** for a transition into rendered form.
- Sci-fi HUD clutter, fake equations, arbitrary measurements, perspective inconsistency, or illegible microtext.
