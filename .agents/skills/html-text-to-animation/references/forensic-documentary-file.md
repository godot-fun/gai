# Forensic Documentary File

## Overview

A hushed investigative case file combines chapter tabs, aged evidence cards, restrained data journalism, labeled testimony, and a slow-turning network emblem.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Best for: A hushed investigative case file combines chapter tabs, aged evidence cards, restrained data journalism, labeled testimony, and a slow-turning network emblem.

## Signature Features

- Near-black field and low-poly network sphere
- Folder-tab chapters and desk-lamp evidence cards
- Minimal bar charts and phrase-by-phrase captions
- Explicitly labeled backlit witness silhouette
- Slow settling motion, hard opening hit, and quiet closing chime

## Style Prompt

Frame the subject as an evidence-led investigation rather than promotion. Open with one hard impact and a slowly rotating low-poly network sphere or relationship emblem on near-black. Divide the argument into numbered folder-tab chapters. Under a warm desk lamp, place aged evidence cards, documents, photographs, maps, timestamps, and source notes; keep each card sparse and legible. Introduce only the charts needed to establish scale or comparison, using restrained bars, timelines, or node diagrams. When testimony is useful, show a backlit silhouette and label it clearly as reenactment, witness account, or illustrative testimony so fiction is not presented as footage. Build narration captions phrase by phrase at a measured pace. Let cards slide, settle, and remain available for later connections. End by revisiting the network with a clarified relationship and a bright but quiet final cue.

## Avoid

sensational red-string clichés everywhere, marketing superlatives, fake quotations, unsupported certainty, frantic zooms, overdesigned dashboards, and unlabeled dramatization.
