# Dark Academia

## Overview

Aged paper, brown-black ink, old books, and scholarly annotation create a learned historical atmosphere.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: history, literature, archives, and intellectual mystery
- Complexity: Moderate

## Signature Features

- Yellowed paper and deep brown ink.
- Classical serif typography.
- Marginal notes and archival marks.
- Low warm illumination.

## Style Prompt

Create a polished HTML animation in the **Dark Academia** style. Compose like a researched folio: primary text, one artifact, and selective annotation. Animate through careful reveals and page-edge light rather than theatrical page turns.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Halloween gothic clichés, illegible cursive, random stains, over-sepia treatment, or crowded antique props.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
