# Directed Relationship Map

## Overview

People or concepts appear as nodes while labeled arrows reveal influence, expectation, or causality.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: family dynamics, social pressure, dependencies, and cause-and-effect

## Signature Features

- Nodes have a clear hierarchy and stable positions.
- Each arrow has a direction and a meaningful label.
- The active relationship is distinct from contextual links.

## Style Prompt

Create a polished HTML animation in the **Directed Relationship Map** style. Reveal nodes first, then draw one directed connection at a time in narrative order. Keep most links cool and quiet, reserve one warm or dashed path for the unresolved relationship, and prevent labels from crossing lines.

## Avoid

- Hairball layouts, arrows without meaning, equal emphasis everywhere, overlapping labels, or moving nodes that make relationships hard to follow.
