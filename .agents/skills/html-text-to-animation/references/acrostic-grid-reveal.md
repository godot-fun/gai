# Acrostic Grid Reveal

## Overview

Lines align so selected initial or internal letters expose a hidden secondary message.

## Metadata

- Collection: Typography and Language Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: revelation, puzzles, layered writing, and key statements

## Signature Features

- Align authentic lines on a stable grid so selected initials or internal letters form a second message without altering wording.
- Reveal the primary reading first, then isolate the hidden column through spacing, weight, or light while preserving both readings.
- For **Acrostic Grid Reveal**, build hierarchy from the writing system itself: baseline, spacing, glyph anatomy, reading direction, and linguistic timing take precedence over illustration.
