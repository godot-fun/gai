# Handmade Clay

## Overview

Rounded clay forms with fingerprints and soft deformation create a playful tactile world.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: light humor, friendly characters, and approachable explanation

## Signature Features

- Finger-impressed clay texture.
- Rounded simplified forms.
- Soft studio-like light.
- Small stop-motion imperfections.

## Style Prompt

Create a polished HTML animation in the **Handmade Clay** style. Animate with deliberate pose-to-pose changes, subtle squash, and visible handmade continuity. Keep sets simple and color families compact.

## Avoid

- Glossy plastic toys, fluid morphing, hyper-smooth motion, sharp edges, or complex realistic textures.
