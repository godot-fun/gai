# Bauhaus Beat Construction

## Overview

A kinetic poster of circles, triangles, bars, and type moving through a strict modular grid with mechanical restraint and musical precision.

## Metadata

- Collection: Motion Graphics Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Red, yellow, blue, black, and paper-white only
- Every position and distance tied to a modular grid
- Rotation around center, vertex, or composition center
- One decisive event per beat
- Linear or restrained ease with no elastic overshoot

## Style Prompt

Establish a visible or implied modular grid before arranging circles, triangles, rectangles, lines, and compact typography. Restrict color to red, yellow, blue, black, and warm white, allowing overlap only when the print logic is intentional. Quantize all positions, dimensions, and travel distances to whole grid units. Move one module per beat through direct translation, flip, crop, scale, or rotation. Alternate rotation around an object's center, one of its vertices, and the overall composition center to create rhythm without chaos. Use linear motion or restrained ease-in-out; stop exactly on grid. Build complexity through phase-shifted arrays and repeated rules, then reduce to a strongly composed final poster. Keep type aligned to the same geometry.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

spring easing, gradients, arbitrary off-grid placement, decorative texture, random colors, continuous camera drift, pseudo-3D perspective, and too many simultaneous events that obscure the beat structure.
