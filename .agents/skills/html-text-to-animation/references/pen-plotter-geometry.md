# Pen-Plotter Geometry

## Overview

A virtual drawing machine constructs exact geometric artwork one continuous mechanical stroke at a time.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: algorithms, precision, design process, and computational craft

## Signature Features

- Uniform-width plotted lines accumulate in a deliberate order with visible registration and restrained pen colors.
- Animate the pen path at believable speed, pause at tool changes, and preserve the final plotted sheet.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.

## Style Prompt

Create a polished HTML animation in the **Pen-Plotter Geometry** style. A virtual drawing machine constructs exact geometric artwork one continuous mechanical stroke at a time. Use composition, timing, color, and camera behavior to make the governing mechanism understandable before adding secondary detail.

## Avoid

- brushlike strokes, impossible teleporting pens, filled vector shapes, or dense linework that crushes text.
- Do not reproduce historical sample copy or hard-coded layouts from source material.
- Do not sacrifice readability for procedural complexity.
