# Gothic Illustration

## Overview

Elongated silhouettes, pointed forms, and black-purple-crimson contrast build elegant unease.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: fear, moral darkness, mystery, and supernatural tension

## Signature Features

- Tall narrow proportions.
- Pointed architectural rhythm.
- Deep black with restrained dark color.
- Fine ornamental silhouette.

## Style Prompt

Create a polished HTML animation in the **Gothic Illustration** style. Use vertical composition, slow encroaching shadow, and selective crimson emphasis. Keep movement deliberate and ceremonial.

## Avoid

- Generic gore, noisy horror textures, neon purple, cute gothic fashion, or constant jump scares.
