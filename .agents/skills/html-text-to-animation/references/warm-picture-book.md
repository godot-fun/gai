# Warm Picture Book

## Overview

Soft shapes, tactile paper texture, and warm color make the frame feel illustrated for a cherished book.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: children's stories, memory, gentle education, and emotional reassurance
- Complexity: Moderate

## Signature Features

- Soft irregular silhouettes.
- Visible paper or dry-media texture.
- Warm harmonious palette.
- Simple storybook staging.

## Style Prompt

Create a polished HTML animation in the **Warm Picture Book** style. Build each frame around one readable action, use slow page-like reveals, and let texture remain subtle enough for text to stay clear.

Adapt the subject, wording, duration, aspect ratio, and rendering technique to the user's material. Preserve the defining visual grammar and keep supplied text unchanged unless rewriting is requested.

## Customizable Elements

- Subject, wording, duration, aspect ratio, palette emphasis, and scene content.
- Use HTML, CSS, SVG, Canvas, WebGL, or generated visual assets as appropriate.

## Avoid

- Glossy vector perfection, hard digital gradients, crowded scenes, or childish typography everywhere.
- Do not copy example brands, characters, or sample copy from the source material.
- Do not sacrifice hierarchy or readability for surface decoration.
