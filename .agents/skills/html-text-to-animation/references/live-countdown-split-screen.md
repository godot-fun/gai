# Live Countdown Split Screen

## Overview

One real event plays in real time while the frame divides into more viewpoints as a known zero approaches.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: launches, verdicts, polls closing, final whistles, and irreversible moments
- Complexity: Advanced

## Signature Features

- Screen time equals event time.
- A visible clock advances every second.
- Additional cells share the same instant.
- All cells merge at zero.

## Style Prompt

Create a polished visual narrative in the **Live Countdown Split Screen** style. Begin with one view and a credible clock, add synchronized perspectives as tension rises, and keep every cell on the same second. At zero, collapse the grid into the decisive image and flip the clock state.

Translate the user's material into this grammar rather than copying the source examples. Preserve supplied wording and factual attribution, and choose an HTML-native or composited implementation appropriate to the evidence and visual material.

## Customizable Elements

- Subject, evidence, copy, duration, aspect ratio, pacing, and implementation method.
- Adapt palette details only when the defining visual hierarchy remains intact.

## Avoid

- Montage that cheats time, unsynchronized feeds, decorative countdowns, or splitting the frame after the decisive moment.
- Never invent documents, measurements, quotations, sources, or factual evidence.
- Do not use surface effects as a substitute for the style's narrative structure.
