# Recursive Fractal Architecture

## Overview

Rooms, arches, or facades repeat at diminishing scales to turn recursion into inhabitable space.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: infinity, nested systems, scale, memory, and self-similarity

## Signature Features

- One architectural module recurs across multiple readable scales while maintaining a stable vanishing logic.
- Travel through nested thresholds or unfold successive levels, marking scale changes with controlled parallax.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.

## Style Prompt

Create a polished HTML animation in the **Recursive Fractal Architecture** style. Rooms, arches, or facades repeat at diminishing scales to turn recursion into inhabitable space. Use composition, timing, color, and camera behavior to make the governing mechanism understandable before adding secondary detail.

## Avoid

- generic kaleidoscopes, arbitrary repetition, incoherent perspective, or endless zoom without narrative beats.
- Do not reproduce historical sample copy or hard-coded layouts from source material.
- Do not sacrifice readability for procedural complexity.
