# Pendulum Harmonograph

## Overview

Coupled damped oscillations draw elegant looping figures whose symmetry slowly decays.

## Metadata

- Collection: Generative Systems
- Medium: HTML, SVG, Canvas, or WebGL
- Best for: rhythm, harmony, decay, music, and physical systems

## Signature Features

- Two perpendicular oscillations with believable frequency ratios and damping generate one continuous trace.
- Start with wide energetic swings, let the line accumulate, and allow amplitude to decay into a quiet center.
- The underlying rule remains visually legible so the effect communicates more than surface decoration.
