# Memphis Figure Illustration

## Overview

Elongated flat figures and playful abstract geometry create a polished corporate-editorial look.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: workplace concepts, services, collaboration, and modern explainers

## Signature Features

- Long simplified limbs.
- Flat organic body shapes.
- Memphis dots, arcs, and blocks.
- Friendly contemporary palette.

## Style Prompt

Create a polished HTML animation in the **Memphis Figure Illustration** style. Use large human gestures and abstract shapes to clarify relationships. Keep decorative geometry subordinate to the action and maintain strong color blocking.

## Avoid

- Generic stock poses, excessive pattern noise, tiny people in huge scenes, or weak contrast.
