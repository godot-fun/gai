# Chibi Character

## Overview

Large heads, compact bodies, and expressive faces turn a subject into an endearing miniature character.

## Metadata

- Collection: Cartoon Styles
- Medium: HTML, SVG, Canvas, WebGL, or generated visual assets
- Best for: friendly mascots, reactions, beginner education, and comic relief

## Signature Features

- Head-to-body ratio around one-to-two.
- Short limbs and large readable eyes.
- Soft rounded silhouettes.
- Gentle low-contrast palette.

## Style Prompt

Create a polished HTML animation in the **Chibi Character** style. Keep poses simple and readable, exaggerate facial timing, and use squash-and-stretch sparingly around emotional beats.

## Avoid

- Infant realism, over-detailed anatomy, sharp aggressive features, or tiny unreadable expressions.
