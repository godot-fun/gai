# Daybreak

## Overview

A deep-blue night gradually warms as the sun rises into a hopeful final state.

## Metadata

- Collection: Code Motion Studies
- Medium: HTML, Canvas, SVG, or WebGL
- Best for: endings, renewal, relief, and new beginnings

## Signature Features

- The sky progresses through a restrained dawn palette.
- Stars fade as ambient light grows.
- The sunrise provides a clear emotional resolution.

## Style Prompt

Create a polished HTML animation in the **Daybreak** style. Use a low horizon, broad sky, slow color evolution, and layered dark silhouettes. Raise the sun gradually, reveal the final line near first light, and hold on an open stable morning state.

## Avoid

- Fast color cycling, oversaturated sunset colors, dramatic lens flare, busy foregrounds, or looping before the ending has time to land.
