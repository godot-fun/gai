# Pepper’s Ghost Stage

## Overview

Angled transparent glass reflects a hidden scene into a visible set, creating a controlled spectral apparition.

## Metadata

- Collection: Architecture and Spatial Installation
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: theatre, history, illusion, and surprising reveals

## Signature Features

- Show a dark audience view with a real set, hidden bright source area, and angled transparent reflector.
- Fade or move the hidden subject so its reflected image shares perspective with the set; keep the audience camera inside the valid viewing cone.
- For **Pepper’s Ghost Stage**, choose a restrained architectural palette led by material color and one light or wayfinding accent; preserve human scale and believable structure.
