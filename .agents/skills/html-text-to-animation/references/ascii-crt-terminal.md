# ASCII CRT Terminal

## Overview

Every visible form is built from real monospaced characters glowing on an old monochrome phosphor display. Choose this when every visible form must be constructed from actual monospaced characters on a phosphor display.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, or WebGL
- Best for: computing history, surveillance, code, identity, and constrained digital worlds

## Signature Features

- Fixed character grid.
- Brightness encoded by glyph choice.
- Phosphor bloom and scan behavior.
- Text and image share one representation.

## Style Prompt

Create a polished visual narrative in the **ASCII CRT Terminal** style. Choose one phosphor color, preserve exact cell alignment, and transform readable text into diagrams or images by changing characters rather than drawing pixels outside the grid.

## Avoid

- Choose **Green Phosphor Command Story** when commands and operational narrative matter more than character-built imagery.
- Proportional fonts, rainbow terminal colors, vector icons, random glyph noise, or CRT effects stronger than the content.
