## Overview

An information-rich isometric world that grows tile by tile under a true orthographic camera, with fixed axes, ordered layering, and parallel camera travel. Choose this when a miniature system must remain dimensionally stable under an orthographic camera without isometric drafting aesthetics.

## Signature Features

- True thirty-degree isometric projection with no vanishing point
- Miniature buildings, rooms, infrastructure, or data systems
- Base tile, rising walls, and delayed roof assembly
- Two-to-one diagonal grid movement and correct depth order
- Parallel sliding camera with layered parallax

## Style Prompt

Use a true orthographic isometric projection and keep all world axes consistent throughout. Build a miniature city, office, factory, server campus, landscape, or process map from modular tiles with readable top, left, and right faces. Maintain scale at every depth and order overlapping objects by their projected position. Assemble structures in a clear sequence: ground tile lands, walls rise vertically from zero, roof or top surface arrives a few frames later, then details and inhabitants activate. Move people, vehicles, signals, or materials along the isometric grid using a consistent two-to-one diagonal slope. Keep lighting soft enough to separate faces and include small shadows and ambient occlusion without introducing perspective. Travel only through parallel pans or a restrained orthographic zoom, with near, middle, and far groups moving at measured parallax rates.
