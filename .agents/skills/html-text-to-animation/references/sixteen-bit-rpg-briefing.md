# Sixteen-Bit RPG Briefing

## Overview

A factual story becomes a console-era quest through dialogue, quest log, battle vignette, level-up, loot, and a final sunset completion card. Choose this when RPG menus, stats, and dialogue boxes organize an explanation rather than a journey.

## Metadata

- Collection: Code Video Styles
- Medium: Cinematic HTML animation
- Source type: visual style reference

## Signature Features

- Fixed-camera pixel diorama with scan lines
- JRPG dialogue box and typed text
- Quest log, stats, progress, and meaningful inventory
- Short battle or challenge vignette
- Level-up burst, loot card, and quest-clear ending

## Style Prompt

Build a fixed-camera pixel-art diorama at a coherent console-era resolution and use an original cast. Open on a night title or village view, then let a character or guide deliver the objective through a JRPG dialogue box with paced typewriter text. Translate factual progress into a quest log, stats, map, or inventory only where the metaphor fits. Stage one compact challenge—battle, puzzle, traversal, repair, negotiation—with readable sprite actions and a clear outcome. Reward progress through a radial level-up screen and a loot or skill card that represents the real result. Keep palette, tiles, sprite scale, scan lines, and UI consistent across every state. Finish on a sunset or transformed-location QUEST CLEAR card.

## Customizable Elements

Adapt the subject, setting, wording, duration, aspect ratio, and narrative emphasis. Adjust individual hues only within the palette roles defined above, and preserve the medium, composition, material behavior, and motion grammar that make the style recognizable.

## Avoid

- Choose **16-Bit Console RPG** for a whole game-world simulation, or **Sixteen-Bit Quest Run** for action-led movement.
