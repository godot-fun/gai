# Microgame Frenzy

## Overview

A command appears, one simple action must happen within seconds, and every round changes art style as tempo accelerates.

## Metadata

- Collection: Lemo Opuscar
- Medium: HTML animation, composited media, SVG, Canvas, WebGL, or generated visual assets
- Best for: rapid humor, variety, audience participation, and escalating challenges
- Complexity: Advanced

## Signature Features

- One imperative command per round.
- One immediately readable action.
- Radically different look per game.
- Tempo increases across the sequence.
