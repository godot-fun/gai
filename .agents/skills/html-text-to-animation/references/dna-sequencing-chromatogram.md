# DNA Sequencing Chromatogram

## Overview

Colored nucleotide peaks resolve into a base sequence while confidence falls where signals overlap.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: genetics, identity, biological data, and uncertainty
- Complexity: Moderate to advanced

## Signature Features

- Use a white laboratory plot with four disciplined trace colors, evenly spaced base calls, confidence shading, and a clear read direction.
- Draw peaks in order, resolve clean calls, then expose overlap or signal decay near uncertain regions; keep the camera orthographic and pan along sequence length.
- Use monospaced base letters and small sans-serif quality annotations aligned to the trace.
