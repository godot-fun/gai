# Lenticular Image Shift

## Overview

Interlaced images switch or animate as the viewing angle crosses narrow lenticular bands.

## Metadata

- Collection: Light and Optical Materials
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: comparison, dual states, playful print, and viewpoint-dependent truth
- Complexity: Moderate to advanced

## Signature Features

- Build the image from narrow vertical interlaces under a visible lenticular ridge pattern; limit the source set to two states or a short ordered sequence.
- Move the viewpoint laterally through discrete viewing zones so images flip, animate, or reveal depth; avoid crossfading and preserve the stepped optical transition.
- Use bold condensed type designed into both interlaced states with identical registration.
