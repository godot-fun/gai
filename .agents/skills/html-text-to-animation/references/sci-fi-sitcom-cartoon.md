# Sci-Fi Sitcom Cartoon

## Overview

A mismatched duo, boiling outlines, flat color, and one palette per world turn science fiction into reaction-driven comedy.

- Medium: HTML animation, composited media, SVG, Canvas, WebGL, or generated visual assets

## Signature Features

- Thick subtly boiling contour.

- Contrasting character reactions.
- Portal provides a visual hinge.
