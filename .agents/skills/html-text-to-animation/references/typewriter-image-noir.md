# Typewriter Image Noir

## Overview

A complete figurative scene struck from typewriter glyphs, ribbon defects, and hard graphic shadow.

## Metadata

- Collection: Academy Award Film Styles
- Medium: Cinematic HTML animation
- Best for: A complete figurative scene struck from typewriter glyphs, ribbon defects, and hard graphic shadow.

## Signature Features

- Fixed monospaced grid filled across eighty-five percent or more
- Glyph ladders from punctuation to overstruck M and hash characters
- Material-specific character vocabularies
- Uneven ribbon pressure and misaligned keys
- A red-orange focal subject with a black shadow

## Style Prompt

Construct the entire image on a fixed typewriter grid whose cells are twice as tall as they are wide. Strike nearly every cell, leaving bare paper only for the brightest highlights. Build a value ladder from sparse punctuation through equals, plus, and rounded letters to X, hash, M, and doubled overstrikes in the deepest third. Preserve crisp silhouette boundaries so the picture reads before individual characters do. Give materials their own repeated marks—vertical letters for structure, underscore-and-bar patterns for masonry, tildes for liquid, slashes for rain—and keep signs or key labels genuinely legible. Simulate a worn ribbon with half-inked impressions, variable darkness, and several keys that consistently sit high or low. Print dark ink on warm paper. Strike the focal figure in a separate muted red-orange ribbon while retaining black for its cast shadow. Use hard side light to create long, dense graphic shadows. Type the image rapidly within the opening beat, then hold long enough to inspect it.

## Avoid

sparse ASCII sketches, decorative text bands with no volume, proportional fonts, and smooth raster shading.
