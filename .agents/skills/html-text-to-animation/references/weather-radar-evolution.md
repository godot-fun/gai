# Weather Radar Evolution

## Overview

Time-stepped reflectivity cells grow, rotate, merge, and decay across a geographic radar field.

## Metadata

- Collection: Scientific Imaging
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: storms, forecasting, risk, and spatial change
- Complexity: Moderate to advanced

## Signature Features

- Use a geographic base with calibrated reflectivity colors, range rings, timestamps, and distinct storm cells rather than a decorative map.
- Advance in fixed time steps as cells initiate, translate, rotate, merge, and decay; keep the map locked and use tracked paths for comparison.
- Use broadcast-clear sans-serif labels, legends, and warnings without covering active cells.
