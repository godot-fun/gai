# Network Packet Observatory

## Overview

Packets traverse nodes and protocols with latency, loss, retries, and bottlenecks made visible.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: networks, cloud systems, performance, and cybersecurity

## Signature Features

- Show protocol layers, endpoints, hops, packet envelopes, latency, loss, retries, and a focused flow inspector.
- Send packets in bursts, queue them at congestion, drop selected frames, and show retransmission or backoff causally.
- For **Network Packet Observatory**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.

## Style Prompt

Create a polished HTML animation in the **Network Packet Observatory** style. Show protocol layers, endpoints, hops, packet envelopes, latency, loss, retries, and a focused flow inspector. Send packets in bursts, queue them at congestion, drop selected frames, and show retransmission or backoff causally. Use a disciplined operational surface with color assigned consistently to status, confidence, ownership, or risk. Set typography in a compact UI sans serif or monospaced face; align values, units, timestamps, and labels to a stable grid. Organize the message around the operational decision so every state change, alert, route, or dependency has a readable cause.

## Avoid

- Avoid generic glowing lines, packets crossing topology arbitrarily, fake encryption claims, or constant equal-speed traffic.
- Do not add dashboard chrome, alerts, metrics, or map layers that do not support the operational decision being shown.
