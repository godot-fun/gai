# Network Packet Observatory

## Overview

Packets traverse nodes and protocols with latency, loss, retries, and bottlenecks made visible.

## Metadata

- Collection: Interfaces and Information Systems
- Medium: HTML, SVG, Canvas, WebGL, or composited media
- Best for: networks, cloud systems, performance, and cybersecurity
- Complexity: Moderate to advanced

## Signature Features

- Show protocol layers, endpoints, hops, packet envelopes, latency, loss, retries, and a focused flow inspector.
- Send packets in bursts, queue them at congestion, drop selected frames, and show retransmission or backoff causally.
- For **Network Packet Observatory**, use a near-black, slate, or warm-white operational surface with one semantic accent and color reserved for status, confidence, or ownership.
